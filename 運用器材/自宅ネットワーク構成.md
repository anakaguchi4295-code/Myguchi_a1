# 🌐 自宅ネットワーク構成

自宅の光回線・ルーター・Wi-Fi環境の構成メモ。WZR-600DHPの故障をきっかけに整理。

---

## 📋 現状構成（機器一覧）

| 機器                                | 役割                       | 設置場所        | 状態                                            |
| --------------------------------- | ------------------------ | ----------- | --------------------------------------------- |
| NTT回線終端装置（ONU）                    | 光回線の終端                   | 1階          | 稼働中                                           |
| **PR-600KI**                      | ルーター（PPPoE接続）／ひかり電話アダプタ  | 1階          | 稼働中。IPv4 PPPoE：ぷらら・常時接続／IPv6 PPPoE：待機中（正常な状態） |
| ~~BUFFALO WZR-600DHP~~            | ~~無線ルーター~~               | ~~1階~~      | **故障**。DIAGランプ常時点灯（エラー表示）、無線・有線とも不調。交換・処分対象   |
| **BUFFALO WSR-3000AX4L/N** | 無線AP（Wi-Fi 6、EasyMesh対応） | **1階に設置済み** | 稼働中。APモードで運用（ルーター機能はPR-600KIに任せる） |

---

## 🏠 各階の機器一覧

**1階**：NTT機器（ONU）／PR-600KI／光電話／PC（有線）／TV（有線）
**2階**：4画面PC（有線）／TV × 2（有線）／タブレット（無線）／ノートPC（無線）

2階のPC・TVは基本的にすべて有線接続。無線が必要なのはタブレットとノートPCのみ。

---

## 🔌 接続構成図

```
[NTT回線]
   │
[PR-600KI]（1階・PPPoE/ひかり電話）
   │
   ├─ [WSR-3000AX4L/N：1階・APモード]
   │     └─ Wi-Fi電波（1階中心、2階にも到達を期待）
   │
   ├─ 1階：TV（有線）／PC（有線）
   │
   └─ 既存LANケーブル
        │
   [スイッチングHUB：2階]
        ├─ 4画面PC（有線）
        ├─ TV × 2（有線）
        ├─ タブレット（無線、1階APの電波を利用）
        └─ ノートPC（無線、1階APの電波を利用）
```

※当初は2階設置（有線バックホールでの直接AP化）を想定していたが、実際は1階に設置。2階のタブレット・ノートPCは1階からの電波を頼る形になる点に注意（詳しくは「今後の拡張余地」参照）。

---

## ⚙️ WSR-3000AX4L/N 設定・設置状況

- **1階に設置済み**（2026-09-04）
- **APモード**で運用（ROUTER/AP切替スイッチを「AP」側にする）
- ルーター機能・DHCP・PPPoE接続はPR-600KIに任せる
- WANポートは未使用。LANポート経由でPR-600KIと接続
- SSID・パスワードのみ設定すればOK

---

## 🔧 WZR-600DHP 故障時のトラブルシューティング記録

- 有線ではネット接続OKだが、Wi-Fi電波（SSID）が出ない状態からスタート
- 切り分けの結果、PR-600KI側のWAN接続は正常と確認（IPv4 PPPoE常時接続）
- その後、1階PCとの有線接続も不可に。DIAGランプが常時点灯（点滅ではなく点灯し続ける＝エラー状態）
- 電源抜き差し・RESETボタン長押し（10秒以上）を試しても改善しない場合はハードウェア故障と判断
- 発売から13年以上経過していたモデルのため、修理より買い替えを選択

---

## 🚀 今後の拡張余地

- WSR-3000AX4L/Nは1階に設置したため、**2階（タブレット・ノートPC）のWi-Fi電波が弱くなる可能性**がある。実際に2階での電波状況を確認すること
- もし2階の電波が弱い場合は、**同機種をもう1台追加**し、既存の1階⇔2階LANケーブルを使って **2階に有線バックホールでEasyMesh子機を設置**（当初想定していた構成）
- 構成：PR-600KI → 1階AP（WSR-3000AX4L/N・EasyMesh親機）→ 2階AP（同機種2台目・EasyMesh子機、有線バックホール）
