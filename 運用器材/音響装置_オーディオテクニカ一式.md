## 🎯 目標：マイク（AT2020）の使用を可能にする

**接続構成**: AT2020 → BX3/3.0（XLRケーブル）→ AT-UMX3（USBミキサー）→ [[デスクトップPC_GALLERIA_RM7R-R56T]]（USB-C）

### セットアップ手順

#### 1. 物理的な組み立て
1. AT8700J（マイクブームアーム）をデスクに固定
2. AT2020（マイク）をブームアームに取り付け
3. AT8175（ポップフィルター）をマイク前面にセット
4. BX3/3.0（XLRケーブル）でマイク ⇔ AT-UMX3の「MIC/LINE入力」を接続

#### 2. AT-UMX3 ⇔ PC接続
- 付属のUSB-Cケーブルで AT-UMX3 ⇔ GALLERIA RM7R-R56T のUSBポートに接続
- ⚠️ ケーブルの抜き差しは、**GAIN・LEVELを最小にしてから**行う（ノイズ・破損防止）

#### 3. ファンタム電源をON（最重要）
- AT2020はコンデンサーマイクのため、AT-UMX3本体の **+48Vスイッチを必ずON** にする
- OFFのままだと音が極端に小さい、または無音になる

#### 4. GAIN調整
- 話しながらGAINつまみを回し、ピークメーターが **-12dBFS付近** になるよう調整
- 音割れが出たらGainを2〜3dB下げる

#### 5. モニター用ヘッドホン接続
- ATH-M20xをAT-UMX3のヘッドホン出力に接続し、自分の声をリアルタイムで確認

#### 6. Windows 11側の設定
1. 設定 → システム → サウンド を開く
2. 入力デバイスで「AT-UMX3（USB Audio）」を選択
3. デバイスマネージャーで「サウンド、ビデオ、およびゲーム コントローラー」欄に認識されているか確認
4. 使用するアプリ（OBS／Zoom／Discordなど）側でも、マイク入力を「AT-UMX3」に個別指定

#### 7. 動作確認
- Windows標準の「ボイスレコーダー」アプリで試し録音し、正常に音が入るか確認

### 進捗チェックリスト

- [ ] マイク・ブームアーム・ポップフィルターの組み立て完了
- [x] AT-UMX3をPCにUSB接続（デバイスマネージャーで認識確認済み・Status: OK）
- [ ] ファンタム電源（+48V）ON確認
- [ ] GAIN調整完了
- [x] Windows側でAT-UMX3を入力デバイスに設定（既定の録音デバイス：マイク(AT-UMX3)、既定の再生デバイス：ヘッドホン(AT-UMX3) いずれも設定済みと確認）
- [ ] 試し録音で音声確認済み

**確認方法**: PowerShellの `AudioDeviceCmdlets` モジュールをインストールし、`Get-AudioDevice -List` で既定デバイスを直接確認。デバイスマネージャーには `USB\VID_0909&PID_005C`（オーディオテクニカ）として認識されている。

### ⚠️ トラブルシューティング履歴

**症状**: AT-UMX3をONにすると外部スピーカーから音が出なくなる

**原因**: このPCには再生デバイスが2つ存在する（🎧 ヘッドホン(AT-UMX3)／🔊 Fosi Audio BT30D＝Bluetoothアンプ経由の外部スピーカー）。AT-UMX3の電源を入れると、Windowsが既定の再生デバイスを自動的にAT-UMX3のヘッドホン出力に切り替えてしまい、外部スピーカー側が無音になる。

**対処**: PowerShellの `AudioDeviceCmdlets` モジュールで `Set-AudioDevice -Index <Fosi Audio BT30Dのインデックス>` を実行し、既定の再生デバイスを外部スピーカーに手動で戻して復旧。マイク側の既定録音デバイス（AT-UMX3）は変更していないため、マイク機能には影響なし。

**恒久対策（未実施）**: Windows 11の「設定 → システム → サウンド → 詳細設定 → アプリの音量とデバイスの設定」で、アプリごとに出力先を個別固定すれば、AT-UMX3をONにしても自動切替されなくなる。

### ⚠️ トラブルシューティング履歴②：ワイヤレスマイクで「録音はできるが再生で音が聞こえない」

**症状**: ボイスレコーダーで録音すると波形（音量メーター）は動く＝録音は成功している。しかし再生しても自分の声が聞こえない。

**原因**: 既定の**再生**デバイスが「Fosi Audio BT30D」（外部スピーカー）になっており、ATH-M20xヘッドホン（AT-UMX3経由）に音が出ていなかった。**録音（マイク入力）と再生（音声出力）は別々のデバイス設定**であり、マイクが正常でも再生デバイスが違えば音は聞こえない。

**背景**：AT-UMX3とFosi Audio BT30Dは、Bluetoothの接続・切断のたびに既定の再生デバイスが自動的に入れ替わる（トラブル①と根は同じ）。

**対処**: PowerShellで `Set-AudioDevice -Index <AT-UMX3のインデックス>` を実行し、既定の再生デバイスをAT-UMX3ヘッドホンに戻して解決。

**教訓**：「音が出ない」系のトラブルは、まず①マイク入力（録音）が機能しているか、②再生デバイスの選択が合っているか、を切り分けて確認すると原因特定が早い。
