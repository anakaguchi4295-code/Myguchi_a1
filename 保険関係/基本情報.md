## 🚗 自動車保険（SBI損害保険株式会社）

**ひとことで言うと**：カローラクロスにかけている自動車保険。相手への賠償は無制限、車両保険（自分の車の修理費）も付いている、バランスの良い内容。

### 💰 補償内容（もしものときにいくら出るか）

| もしものとき | 補償の内容 |
|---|---|
| 🚑 相手にケガをさせた（対人事故） | **無制限**（何百万円かかっても保険で全額カバー） |
| 🏠 相手の車や物を壊した（対物事故） | **無制限**（自己負担0円） |
| 🤕 自分や同乗者がケガをした | 搭乗者傷害保険金**2,000万円**（1名につき）＋人身傷害の基準で補償 |
| 🚗 相手が無保険だった場合 | 無保険車傷害保険金**無制限** |
| 🔧 自分の車が壊れた・盗まれた（車両保険） | 最大**45万円**（自己負担：1回目5万円、2回目以降10万円） |
| 👜 車上荒らしで車内の物を盗まれた | 最大**30万円**（自己負担3,000円） |
| ⚖️ 日常生活で他人に賠償責任を負った場合 | 個人賠償責任保険**無制限**（自動車事故以外でも使える） |
| 👨‍⚖️ 事故で弁護士が必要になった場合 | 弁護士費用等補償特約あり |
