## 🏆 最も期待される企業＝ディスコ（6146）

AI・半導体分野の「本命」として複数の記事で名指し。半導体ウエハを切り出す**ダイシングソー**、研削する**グラインダ**で**世界シェア約7〜8割**を握るリーディングカンパニー。半導体製造の必須工程を担う「ピック・アンド・ショベル型」投資先。

### 株価・valuation（2026-08-02時点）

| 項目 | 内容 |
|---|---|
| 株価 | ¥52,560（2026/7/30、前日比+2.42%） |
| 時価総額 | 約7.53兆円 |
| PBR | 12.83倍（かなり割高な水準） |
| アナリスト平均目標株価 | ¥82,765（現値から+57%の上値余地） |
| コンセンサス | 強気買い10人・買い2人・中立9人（弱気ゼロ） |
| 直近決算（27/3期1Q） | 売上高+27.1%、営業利益+42.2%、純利益+44.0%（AI需要による大幅増収増益） |

### 補足：ラピダスとの関係
政府投資額として最大なのはラピダス（半導体量産、支援総額2.9兆円）だが**非上場のため直接投資不可**。市場では「ラピダス関連銘柄」として、東洋経済が挙げる14銘柄などサプライチェーン企業群に資金が向かう構図。

## 🤖 保有銘柄チェック：安川電機（6506）

17分野には明示されていないが、「AI・半導体」需要や政府の**AIロボティクス戦略**とも連動するロボット・モーションコントロール大手。すでに300株保有中（[[投資関連/日本株売買/最終評価表_2026-07-23.md]]参照）。

### 株価・valuation（2026-08-02時点）

| 項目 | 内容 |
|---|---|
| 株価 | ¥4,867（7/31時点） |
| 決算（27/2期1Q、7/10発表） | 売上収益+10.6%（半導体・データセンタ需要拡大）、営業利益**-19.2%**（基幹システム移行費用・欧州事業構造改革費用） |
| 決算後の値動き | 7/10終値6,972円→7/14終値5,436円（2日で-22%の急落）、7/31時点4,867円まで軟調 |
| アナリスト平均目標株価 | ¥7,000（現値から+43.8%の上値余地） |
| コンセンサス | 強気買い8人・買い3人・中立5人・売り1人 |

### 保有ポジションへの影響
- 2026/7/13の追加購入（100株@6,030円）が急落の真っ只中だったため、**この新規ロットは-19.3%の含み損**
- ただし保有全体（300株、平均取得単価4,092円）では2015年取得の激安ロット（100株@1,525円）が支えとなり、**全体では+232,200円（+18.9%）の含み益を維持**（2026-08-02更新後の数値）

### 期待材料
- 次世代AIロボットの量産開始
- 政府の「AIロボティクス戦略」の後押し
- データセンタ向けインバータ（米国）の伸び
- 27/2期通期は増収増益予想（売上5,800億円+7.0%、営業利益600億円+26.8%）

### 見立て
決算の「営業利益急減」は基幹システム移行・欧州構造改革という一過性寄りのコスト要因。次回決算（10月頃）でこれらが落ち着くかが試金石。アナリストの強気目標株価（+43.8%）は中期的な需要テーマ（AI×ロボット）を支持している。
