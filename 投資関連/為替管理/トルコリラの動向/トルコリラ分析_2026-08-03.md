## 🧮 買い増しの内訳（推定）

差分から逆算すると、今回の買い増しはおおよそ以下の内容と推定されます：

```
買付量：7,200,000 TRY
買付単価（推定）：約3.391円/TRY
買付代金（推定）：約24,413,900円

計算根拠：
  旧建玉総額 = 30,100,000 × 3.517円 = 105,861,700円
  新建玉総額 = 37,300,000 × 3.492円 = 130,275,600円
  → 差額 24,413,900円 ÷ 7,200,000 TRY = 約3.391円
```

**3.391円で買った後も、レートはさらに3.324円まで下落**しており、下げ相場の途中で買い増しに踏み切った形です。下げ買い戦略（[[TRY_スワップ複利戦略_2026-07-25]]）に沿った動きですが、結果として一時的な含み損拡大を招いています。

```

新総合評価損益 ≈ -3,225,330 - 12,388,600 = -15,613,930円
新実質保証金 ≈ 43,764,070円
```

→ **さらに10%下落してもロスカットには程遠い水準**。ただし、レバレッジが1.69倍→2.19倍に上昇しており、今後の買い増しペースには注意が必要です。
