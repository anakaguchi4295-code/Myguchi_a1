# 🌍 トルコ政治情勢とドルの行方（2026年8月時点）

**記録日**: 2026年8月31日
**目的**: トルコリラ（TRY）ポジションのリスク要因（政治・金融政策）を定期的に把握するための情勢メモ（[[トルコ政治情勢とドル動向_2026-07|前回7月版]]の更新）

---

## 🚨 最大の変数：2026年イラン戦争とその余波

7月時点のメモでは触れていなかった最大級のイベントとして、**2026年2月28日に米国・イスラエルがイランを攻撃し開戦**（イラン最高指導者ハメネイ師を含む要人を殺害）。3月にはイランの弾道ミサイルがトルコ領空を通過し、東地中海配備のNATO部隊がこれを撃墜する事態も発生しました。

- トルコは「第三者的立場」を維持し中立姿勢（戦争に加担せず、挑発にも乗らない）を貫いている
- ただしトルコは天然ガス消費の15〜25%をイランに依存しており、紛争長期化はトルコ経済への打撃が大きい
- この地政学リスクを受け、**トルコ中銀は3月に事実上の緊急利上げ**（資金供給を政策金利37%から翌日物40%へ切り替える"ステルス利上げ"）を実施していた
- 8月に入り「イラン戦争の最悪期は過ぎた」との判断から、**8月23〜24日に資金供給を政策金利37%へ戻す正常化ステップ**を実施。トルコ銀行株が大幅上昇（BISTバンク指数 +4.1%）

→ 7月時点では「懸念材料はインフレのみ」という整理でしたが、実際には**中東情勢というより大きな地政学リスクが3月から進行中**だったことが判明。8月は危機のピークアウトが確認された局面と位置付けられます。

## 🇹🇷 エルドアン政権・国内政治の動向

- **CHP（最大野党）への締め付けは継続**：イマモール氏（イスタンブール市長・エルドアン氏最大のライバル）の拘束は継続中とみられるが、8月時点での続報は限定的
- 8月17日付Turkish Minute論説：AKP結党25年を機に「改革から一人支配へ」と評する厳しい報道あり。権威主義的傾向への懸念は根強い
- **外交面では中東での存在感拡大**：8月、サウジアラビア・パキスタンとの防衛協力を強化する「メッカ共同防衛協定」を締結。イラン戦争を機に地域バランサーとしての役割拡大を模索
- **クルド和平プロセスは前進**：8月、PKKメンバーの武装解除検証・恩赦のための委員会設置法制化がオジャラン氏の支持を得て議会を通過。政治的安定要因としてはプラス材料

### 新たなリスク要因：対イラン制裁の波及懸念

米国による対イラン取引の「二次制裁」強化観測が浮上。**トルコの金融機関が制裁対象に含まれる可能性**が、8月下旬時点での新たな懸念材料として市場で意識されている（TRY/JPY 8/25記事より）。

### インフレ

- 7月CPI：前年比+31.75%（6月の32.11%からわずかに改善）
- 8月13日公表のインフレ報告：2026年末インフレ見通しは**28%**（据え置き、目標15%達成は依然困難視）

## 💵 金融政策と為替の動き

### トルコ中央銀行（CBRT）

| 項目 | 数値 |
|------|------|
| 政策金利（1週間レポ金利） | 37%（7月・8月とも据え置き） |
| オーバーナイト貸出金利 | 40%（据え置き） |
| オーバーナイト借入金利 | 35.5%（据え置き） |
| 8月の変更点 | 3月の危機対応（翌日物40%での資金供給）から、政策金利37%での通常運用に**正常化** |

次回会合は**2026年9月10日**予定。声明内容が注目される。

### TRY/円相場

- **8月25日時点：3.30〜3.31円**（週間予想レンジ3.24〜3.35円、やや下値模索）
- 支持線3.28〜3.30円（割れれば3.24円が視野）、抵抗線3.32〜3.35円
- 高金利という「防波堤」が、資金供給正常化（実質的な緩和）により相対的に低くなりつつあるとの分析

### 米ドル・日本円

- **7〜8月の日米協調円買い介入が総額15兆3,993億円に到達**。単月ベースで過去最大（4〜5月の11兆7,000億円を上回る）
- それでも円安トレンドの明確な反転は見られず、「時間稼ぎ」との評価が市場では多い
- **日銀の次回利上げ観測が9月会合（9月17・18日予定）に急浮上**：OIS市場では9月の確率を約80%まで織り込む場面も。ただしBloombergエコノミストは10月の方が有力とし、野村證券はメインシナリオ「12月・2027年6月」、リスクシナリオ「10月」利上げを想定するなど、市場予想は割れている
- 構造的な円安要因（日本企業の対外直接投資モデルへのシフトなど）も指摘されており、「利上げだけでは円高定着は見込みにくい」との分析も
- ドル円レンジ予想は155〜165円、年末にかけ165円前後との見方も根強い

| **既存の下げ買い戦略との整合性** | 良好。8月中も推定3.30円台での買い増しが継続実行できており、緩やかな下落シナリオと整合的 |
| **最大の警戒点（更新）** | ①対イラン二次制裁のトルコ金融機関への波及可否、②イラン戦争の再燃有無、③CBRTのさらなる緩和ペース |
