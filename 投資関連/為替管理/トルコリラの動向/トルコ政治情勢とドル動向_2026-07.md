# 🌍 トルコ政治情勢とドルの行方（2026年7月時点）

**記録日**: 2026年7月25日  
**目的**: トルコリラ（TRY）ポジションのリスク要因（政治・金融政策）を定期的に把握するための情勢メモ

---

## 🇹🇷 トルコの政権動向

### **エルドアン政権は安定・むしろ強化傾向**

- 6月のイラン・イスラエル（米）停戦仲介で外交的得点。「危機の際に頼れるリーダーは誰か」との問いに **54%がエルドアン氏を支持**
- 主要野党CHPへの締め付けが継続中
  - 3月：イスタンブール市長イマモール氏（エルドアン氏最大のライバル）を拘束
  - 5月：前党首オゼル氏も法廷でCHP党首を解任
  - 7月21日：オゼル氏が新党結成を発表 → **野党分裂は皮肉にもエルドアン続投に有利**に働くとの分析（Al-Monitor）
- PKK（クルド労働者党）との和平は前進（5月に解散・武装解除を宣言）→ 地政学リスクはやや後退
- 次期大統領選は2028年5月予定。憲法上エルドアン氏は本来3期目に出馬できないが、前倒し選挙での再出馬模索の可能性も指摘されている

### **懸念材料：高インフレの継続**

- インフレ率 32〜33%で高止まり（2026年7月時点 CPI前年比32.11%）
- 政府・中銀目標「2026年末15%」の達成は多くの専門家が困難視

---

## 💵 ドル・トルコリラの金融政策と為替見通し

### **FRB（米ドル全体）**

- 6月FOMCで政策金利 3.50〜3.75% に据え置き
- 2026年中の大幅利下げには消極的姿勢。市場予想も年内1回程度の利下げに留まる見方が優勢
- **→ ドルは底堅め**。ドル円は2026年後半、160円台前半での推移を予想する声が多い

### **トルコ中央銀行**

- 7月会合でも政策金利 **37.0%** を据え置き、利下げ再開には慎重姿勢
- トルコ中銀サーベイ（市場参加者調査）：年末の政策金利は **34.70%** 程度と緩やかな低下を予想

### **USD/TRY 年末予想（機関により幅あり）**

| 機関 | 予想USD/TRY（年末） |
|------|---------------------|
| Goldman Sachs | 48（2026年7月時点予想） |
| Morgan Stanley | 44（Q4） |
| トルコ中銀サーベイ | 51.55 |
| Long Forecast | 51.99（12月） |

### **TRY/円への示唆**

- 現在のTRY/円：約 **3.46円**（2026年7月21日時点）
- USD/JPYが160〜162円で横ばいと仮定した場合、年末のTRY/円は概算で **3.10〜3.35円レンジ** への緩やかな切り下がりが示唆される
- 2023年半ば以降の「管理された下落（managed depreciation）」路線が継続：USD/TRYは年7〜9リラ程度の緩やかなペースで下落する傾向

---

## 📌 現在のポジション（29,500,000 TRY、平均建単価3.524円）への示唆

| 要素 | 評価 |
|------|------|
| **急落リスク** | 低め（「管理された下落」路線が続く限り、大暴落型のシナリオは相対的に低確率） |
| **緩やかな下落圧力** | あり（年末にかけて3.10〜3.35円レンジまで下がる可能性） |
| **スワップ収入** | 政策金利37%の高金利は当面維持 → 下支えとして機能継続の見込み |
| **既存の買い増し戦略との整合性** | 良好。3.50円→3.45円→3.40円での段階的買い増し計画は、緩やかな下落シナリオと整合的 |
| **最大の警戒点** | インフレ目標未達・政治不安定化・野党弾圧の激化など、政権の統制力低下につながる急変イベント |
