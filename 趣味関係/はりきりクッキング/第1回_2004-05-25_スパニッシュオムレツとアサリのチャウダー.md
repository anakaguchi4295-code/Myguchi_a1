## 🍴 料理1：スパニッシュオムレツ

### **材料（5名分）**

| 材料 | 分量 | 備考 |
|------|------|------|
| 卵 | 5個 | - |
| ベーコン | 30g | 細切り |
| 玉ねぎ | 150g | うす切り |
| メークイン/じゃがいも | 150g | 5mm厚切り |
| オリーブオイル | 30ml | - |
| 青ねぎ | 3本 | 小口切り |
| 赤パプリカ | 1個 | 皮むき、角切り |
| アンチョビー缶ガープ | 3個 | 細切り |
| 塩 | 小さじ1杯 | - |

### **調理工程**

#### **準備（約10分）**
```
① ベーコン 30g を細切りにする
② 玉ねぎ 150g をうす切りにする
③ じゃがいも 150g を 5mm 厚さにスライス
④ 卵 5個を割ってよく混ぜる
⑤ 赤パプリカ 1個を皮むきして角切り
⑥ 青ねぎ 3本を小口切り
⑦ アンチョビー缶から 3個を取り出して細切り
```

#### **Step 1: じゃがいも調理（約5～7分）**
```
① フライパンにオリーブオイル 30ml を熱する
② じゃがいも（5mm厚切り）を両面カリッと焼く
   - 強火で片面 2～3分
   - 塩を少々振る
③ 焼き色がついたら皿に取り出す
```

#### **Step 2: 具材の炒め（約5分）**
```
① 同じフライパンにベーコンを入れる
② 玉ねぎを加えてしんなりするまで炒める（約3分）
③ 焼いたじゃがいも、赤パプリカを加える
④ 青ねぎ、アンチョビーを加える
⑤ 全体を軽く混ぜる
```

#### **Step 3: 卵液を流す（約8～10分）**
```
① 卵 5個を別碗でよく混ぜる
② 塩 小さじ1杯を加える
③ フライパンの具材に卵液を注ぐ
④ 弱～中火で、フライパンの上から頭火（オーブンの熱）でゆっくり焼く
   OR 弱火で 8～10分焼く
```

#### **Step 4: 完成（約2分）**
```
① 表面が軽く焦げて、内側がしっかり火が通ったら完成
② フライパンから皿に滑らせる
③ 6等分にカットして盛り付け
```

### **調理時間**
- 準備時間: 約10分
- 調理時間: 約15～20分
- **合計**: 約25～30分

### **難易度**
⭐⭐⭐☆☆ **中級**

### **コツ・ポイント**
✅ じゃがいもは事前に焼いておく（中まで火が通る）  
✅ 卵液は塩を加えてよく混ぜる  
✅ 弱～中火で焼く（焦げを防ぐ）  
✅ 頭火（オーブン熱）を使うと火が通りやすい

## 🍲 料理2：アサリのチャウダー

### **材料（5名分）**

| 材料 | 分量 | 備考 |
|------|------|------|
| アサリ | 400g | 200ml の塩で砂を出す、口が開いた物から取り出す |
| ベーコン | 2枚 | - |
| 玉ねぎ | 100g | - |
| セロリー | 50g | - |
| 人参 | 50g | - |
| キャベツ | 200g | - |
| バター | 30g | - |
| 強力粉 | 30g | - |
| ミルク | 500ml | - |
| クラッカー | 5枚 | - |
| 塩 | 200ml | 砂抜き用 |

### **調理工程**

#### **準備（約30分 + 砂抜き時間）**
```
① アサリ 400g を 200ml の塩水に 30分浸す（砂抜き）
② 塩水を捨てて、新しい水で軽く洗う
③ ベーコン 2枚を 1.5cm 角切り
④ 玉ねぎ 100g を 1.5cm 角切り
⑤ 人参 50g を 1.5cm 角切り
⑥ セロリー 50g を 1.5cm 角切り
⑦ キャベツ 200g を 1.5cm 角切り
```

#### **Step 1: アサリの加熱（約5分）**
```
① 別の鍋で水を沸かす
② アサリを入れる
③ 口が開いたものから取り出す
④ 汁は取っておく（スープに使う）
⑤ 身を取り出す
```

#### **Step 2: ルーの作成（約10分）**
```
① バター 30g をフライパンに溶かす
② ベーコンを炒める（約1分）
③ 玉ねぎ、人参、セロリーを加えて炒める
   （約5分、しんなりするまで）
④ キャベツを加えてさらに炒める（約2分）
⑤ 強力粉 30g をふりかけ、よく混ぜながら炒める
   （粉っぽさがなくなるまで）
```

#### **Step 3: スープ化（約10分）**
```
① アサリの汁を加える
② ミルク 500ml を加える
③ 塩で味を整える
   （アサリが塩辛いので、少なめから始める）
④ 中火で 5～10分煮込む
```

#### **Step 4: 仕上げ（約2分）**
```
① 最後にアサリの身を加える
   （加熱しすぎると固くなるので、仕上げに）
② 味を再度確認して調整
③ 盛り付けと同時に、揚げたクラッカー 5枚を振る
   （食べる時にカリカリの食感が出る）
④ 黒こしょうを少々振る
```

### **調理時間**
- 砂抜き時間: 約30分
- 準備時間: 約10分
- 調理時間: 約20～25分
- **合計**: 約55～65分

### **難易度**
⭐⭐⭐⭐☆ **中級～上級**

### **コツ・ポイント**
✅ アサリはしっかり砂抜きする  
✅ アサリの汁はしっかり活用（旨味の源）  
✅ 強力粉でとろみをつける（ダマを避ける）  
✅ アサリは最後に加える（固くならない）  
✅ クラッカーは食べる直前に加える（カリカリ保持）
