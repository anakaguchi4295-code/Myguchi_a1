## 🥣 料理1：小松菜のクリームスープ

### **材料（5名分）**

| 材料 | 分量 | 備考 |
|------|------|------|
| 小松菜 | 1把 | 塩と葉を分けてザク切り |
| 玉ねぎ | 200g | みじん切り |
| 強力粉 | 25g | - |
| バター | 25g | - |
| ブイヨン | 500ml | - |
| 35%生クリーム | 100ml | - |
| 塩 | 少々 | - |
| 白ショウ | 少々 | 白コショウ |

### **調理工程**

#### **Step 1: ベースの作成（約5分）**
```
① 玉ねぎをバターで炒める
② 強力粉をふり入れる
③ 粉が混ざるまで弱火で炒める
④ ブイヨン 500ml を加える
```

#### **Step 2: 煮込み（約10分）**
```
① ブイヨンを加えてから10分煮る
② 小松菜の茎を入れる
③ 一度煮立たせてから小松菜の葉を入れる
④ ミキサーで撹拌してなめらかにする
```

#### **Step 3: 仕上げ（約2分）**
```
① 鍋に戻す
② 生クリーム 100ml を加える
③ 塩、白ショウで味を整える
④ 温かいまま盛り付け
```

### **調理時間**
- 準備時間: 約5分
- 調理時間: 約15～20分
- **合計**: 約20～25分

### **難易度**
⭐⭐⭐☆☆ **中級**

### **コツ・ポイント**
✅ 玉ねぎと小松菜の甘みが大切  
✅ 強力粉でとろみをつける（ダマに注意）  
✅ ミキサーで滑らかにすることで本格的な食感  
✅ 仕上げに生クリームを加えて贅沢に

## 🍖 料理2：ポークフィレカツレツ ウィーン風

### **材料（5名分）**

| 材料 | 分量 | 備考 |
|------|------|------|
| 豚フィレ | 5枚 | 70～80g/枚 |
| 細かいパン粉 | 適量 | - |
| 強力粉 | 適量 | - |
| 玉子 | 2個 | - |
| バター | 50g | - |
| サラダオイル | 50g | - |
| レモン | 1/2個 | 薄切り |
| 塩 | 少々 | - |
| 黒ショウ | 少々 | 黒コショウ |

### **調理工程**

#### **Step 1: 下準備（約5分）**
```
① 豚フィレを平らに伸ばす
② 塩、黒ショウを振る
③ ナイフの端で刻目をつける（見た目と食感向上）
```

#### **Step 2: パン粉付け（約3分）**
```
① 強力粉をふりかける
② 溶いた玉子にくぐらせる
③ パン粉を付ける
④ パン粉がしっかり付くようにやさしく押す
```

#### **Step 3: 焼く（約8～10分）**
```
① バター 50g + サラダオイル 50g を熱する
② 温度が上がったらフィレを入れる
③ 中火で焼く
④ フライパンに入れたらすぐ動かさない（火の通りを均等に）
⑤ 片面 4～5分で反して、もう片面 4～5分
```

#### **Step 4: 完成（約2分）**
```
① 焼き上がったら皿に盛る
② レモンスライスを上に乗せる
③ 温かいまま召し上がる
```

### **調理時間**
- 準備時間: 約5分
- 調理時間: 約15～18分
- **合計**: 約20～23分

### **難易度**
⭐⭐⭐⭐☆ **中級～上級**

### **コツ・ポイント**
✅ 豚フィレは常温に戻してから焼く  
✅ フライパンの温度を十分に上げる  
✅ 焼き始めたら動かさない（カリカリの食感を作る）  
✅ レモンの酸味が豚フィレの脂を引き立たせる  
✅ ウィーン風 = パン粉でコーティングして焼く

## 🥗 料理3：コールスロー

### **材料（5名分）**

| 材料 | 分量 | 備考 |
|------|------|------|
| キャベツ | 400g | 千切り |
| 人参 | 100g | 千切り |
| 玉ねぎ | 100g | みじん切り |
| 白ワイン酢 | 15ml | - |
| EXオリーブオイル | 15ml | - |
| キャラウェイシード | 小さじ1杯 | 独特の香り |
| 塩 | 8g | - |
| 砂糖 | 小さじ1/2杯 | - |

### **調理工程**

#### **Step 1: 野菜の準備（約10分）**
```
① キャベツ 400g を千切りにする
② 人参 100g を千切りにする
③ 玉ねぎ 100g をみじん切りにする
④ すべてボウルに入れる
```

#### **Step 2: 塩漬け（約15～20分）**
```
① 塩 8g をふりかける
② よく混ぜる
③ 15～20分置いて、野菜から水が出るのを待つ
④ 時間が経ったら、ザルで水をしっかり切る
⑤ 手で絞りながら水気をしっかり取る
```

#### **Step 3: ドレッシング（約3分）**
```
① 別のボウルに白ワイン酢 15ml を入れる
② EXオリーブオイル 15ml を加える
③ 砂糖 小さじ1/2杯を加える
④ キャラウェイシード 小さじ1杯を加える
⑤ よく混ぜる
```

#### **Step 4: 仕上げ（約2分）**
```
① 水切りした野菜にドレッシングをかける
② よくよく和える
③ 冷蔵庫で冷やす
```

### **調理時間**
- 準備時間: 約10分
- 塩漬け時間: 約15～20分
- ドレッシング時間: 約5分
- **合計**: 約30～35分

### **難易度**
⭐⭐☆☆☆ **初級～中級**

### **コツ・ポイント**
✅ 塩漬けで野菜の余分な水分を取る（シャキシャキ食感を保つ）  
✅ 絞るときは時間をかけてしっかり水を切る  
✅ キャラウェイシードは独特の香りが特徴（ドイツ・東欧料理に使用）  
✅ オリーブオイルの質が仕上がりに大きく影響  
✅ 冷やすと味がなじんでより美味しくなる
