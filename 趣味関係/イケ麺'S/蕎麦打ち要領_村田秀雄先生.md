## 🎯 そば打ち手順（19ステップ）

### **第1段階：粉の準備と最初の水加え**

```
【ステップ 1】粉をふるう
→ そば粉を「ふるい」にかけたら、こね鉢に入れる

【ステップ 2】粉を混ぜる
→ 両手の爪を立ててかき回す（5～6回）

【ステップ 3】穴を作る
→ 粉を山にして、真ん中に穴をあける

【ステップ 4】最初の水を入れる
→ 真ん中の穴に水 150cc を入れる（1回目）

【ステップ 5】混ぜ始める
→ 指1本で 2～3回かき混ぜる（10回ぐらい円を書くように）

【ステップ 6】粉末状にする
→ 両手の爪を立ててかき回す（粉末になるまで）
```

### **第2段階：段階的な水加え（粉末から小粒へ）**

```
粉末になったら

【ステップ 7】2回目の水を入れる
→ 水 50cc を入れる

【ステップ 8】混ぜ続ける
→ 両手の爪を立ててかき回す（少し小粒ができる）

【ステップ 9】3回目の水を入れる
→ 水 20～30cc ぐらい を入れる

【ステップ 10】大粒ができる
→ 大粒ができたら次段階へ
```

### **第3段階：手洗いと本こね**

```
【ステップ 11】手を洗う
→ 鉢の中を清潔にするため、手を洗う

【ステップ 12】こねる
→ 本格的にこねる（滑らかな生地になるまで）
```

### **第4段階：成型（菊ねり～円盤～角だし）**

```
【ステップ 13】菊ねり
→ 菊の花のような形にこねる（技法）

【ステップ 14】へそ出し
→ 生地の中心部を引き出す

【ステップ 14】円盤
→ 円形に成型する

【ステップ 15】丸だし
→ 上から押して丸くする
→ 直径 50cm から 60cm ぐらいになるまで

【ステップ 16】角だし
→ 丸いものを正方形にする（3段階打ち）

【ステップ 17】たたむ
→ 蕎麦を三つ折りにする
```

### **第5段階：切る・保存**

```
【ステップ 18】切る
→ そば包丁で均等に切る

【ステップ 19】保存する
→ 乾燥させるか、冷蔵保存
```

## 🔥 「茹で」について

### **茹で方のポイント**

1. **鍋の準備**
   - 鍋に水を入れて、火にかける
   - **火は強火にする** ⚡
   - 沸騰したら、蕎麦を一握みし、ほぐしながら鍋に入れる

2. **茹でている間**
   - 鍋に入れたら、菜箸（長い箸）で鍋の底に付かないように蕎麦を 2回ほど十字になでる

3. **茹で時間**
   - **蕎麦の細さにもよりますが、極細でしたら 10秒から 15秒でざるですくい上げる** ⏱️
   - 目安：細め → 10～15秒

**⚠️ 重要**：茹で過ぎないこと！蕎麦の食感を活かすため

---

## 🚿 「洗い」について

### **洗い方の基本手順**

1. **準備**
   - 大きいのボールにざるを入れ、水もたっぷり入れておく

2. **最初の洗い**
   - ゆであがった蕎麦を入れる
   - 水道の水を出しながら **優しく丁寧に洗う**
   - **⚠️ 重要**：たっぷりな水の中で優しく洗うこと

3. **複数回の水替え**
   - ボールの水を **3回ほど取り替えながら洗う**

4. **水切り**
   - 洗い終わったら **水を切り盛り付ける**

5. **重要な心得**
   - 盛り付けたら **時間を空けないですぐ食べること** 🍽️
   - 折角の美味しいお蕎麦が **のびてしまいます**

**💡 ポイント**：速度よりも、丁寧さと優しさが大切

## 🎓 村田秀雄先生の蕎麦打ち哲学

### **先生からのメッセージ**

> **「以上が、蕎で方です。**
> 
> **これが正しい蕎で方ではありませんが、私のいつもの方法です。**
> 
> **どうか、自分なりに工夫をしてください。**
> 
> **今後も何分からないことがありましたら、いつでもお問い合わせください。**
> 
> **私も分からないことがありましたら問べておきます。お互いに勉強です。」**

### **先生の基本理念**

| 理念 | 説明 |
|------|------|
| **1. 「正しい」の否定** | 「これが唯一正しい方法」ではなく、「私のいつもの方法」である |
| **2. 自分なりの工夫** | 基本を学んだ後、各自が工夫し改良していくことを期待 |
| **3. 継続的な学習** | 質問があれば、いつでも応じる姿勢 |
| **4. 相互学習の精神** | 先生自身も分からないことは尋ねるという謙虚さ |
| **5. 「お互いに勉強」** | 先生と生徒が対等に学び合う関係 |

**要するに**：村田先生は、*基本を大切にしながらも、個人の創意工夫を尊重する寛容な教育観* を持っています。
