## 📦 保管・品質管理

### **保管方法**

```
【推奨】
  容器：密閉ビン/タッパー
  場所：冷蔵庫（5℃以下）
  湿度：40～50%（除湿剤を使用）
  
【開封前】
  期限：購入後6ヶ月OK
  
【開封後】
  期限：2～3ヶ月以内に使用
  （風味と品質の低下を防ぐ）
```

### **品質チェックリスト**

```
使用前に確認:
  ✅ 色が黄色くないか（黄ばみ = 劣化）
  ✅ 香りに異臭がないか
  ✅ 虫が混入していないか
  ✅ 湿度が適切か（手に取るとさらさら）
  
問題があれば交換する
```
