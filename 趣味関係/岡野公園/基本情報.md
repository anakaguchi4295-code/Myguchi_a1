## 🎯 このバラ園の特徴的なポイント

### **1️⃣ バラ育成国の多様性**

```
🇩🇪 ドイツ（11種）：最多
🇫🇷 フランス（9種）：メイアン社の傑作多数
🇯🇵 日本（8種）：京成バラ園芸が中心
🇺🇸 アメリカ（5種）
🇬🇧 イギリス（1種）：プリンセスミチコ
🇨🇳 中国（1種）：原種 ナニワイバラ
```

**意味**: 世界中の優れたバラ育成の歴史を学べる

---

### **2️⃣ 時代別バラの進化**

```
【戦前～1960年代（古典）】
- ピース（1945）— 戦後平和の象徴
- クイーン エリザベス（1954）— グランディフローラの創出
- アイスバーグ（1958）— フロリバンダの最高傑作
- プリンセスミチコ（1966）— 日本の皇后を名前に冠した唯一のバラ

【1970年～1990年代（中期）】
- 様々な育成家による実験的品種

【2000年代（最新）】
- ローズヨコハマ（2000）— 横浜を代表するバラ
- 常夏（2005）— 日本の夏を象徴するバラ
```

**意味**: バラ育成の60年間の歴史を一堂に学べる

---

### **3️⃣ 日本関連のバラ**

```
日本作（京成バラ園芸）：8種類
- 万葉（Manyou, 1988）
- 正雪（Masayuki, 1992）
- 賛美（Sanbi, 1991）
- 銀世界（Ginsekai, 1997）
- ローズヨコハマ（Rose yokohama, 2000）
- 常夏（Tokonatsu, 2005）

日本記念（横浜関連）：2種類
- はまみらい（横浜開港150周年記念, 2009年記念）
- ローズヨコハマ（横浜市代表バラ, 2000年作）

日本皇族を名前に冠したバラ：1種類
- プリンセスミチコ（日本の皇后陛下）
  ← 世界中のバラの中でも極めて稀な栄誉
```

---

### **4️⃣ 著名なバラの集中**

```
【世界的に有名なバラ 3つ】
1. ピース（Peace, 1945）
   → 戦後平和を象徴
   → 最高級のバラの代表例

2. クイーン エリザベス（Queen Elizabeth, 1954）
   → グランディフローラという新分類を確立
   → バラの女王の実名で命名

3. アイスバーグ（Iceberg, 1958）
   → フロリバンダローズの最高傑作
   → 世界で最も栽培されているバラ

【これら3つすべてが岡野公園に揃っている】
→ バラ愛好家にとって聖地的な存在
```

## 🌍 バラの文化的意義

### **バラが象徴するもの**

```
ピース（Peace）→ 戦後平和の願い
クイーン エリザベス → 王妃の優雅さ・権威
プリンセスミチコ → 日本の皇后陛下の美しさ
ナニワイバラ → 大阪の市花
ローズヨコハマ → 横浜の発展
```

**横浜での意義**：
- 開港から150年を記念したバラ園
- 日本の重要な文化遺産
- バラ愛好家の学習地
