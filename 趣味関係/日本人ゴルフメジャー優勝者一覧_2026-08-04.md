# ⛳ 日本人ゴルフメジャー優勝者一覧

**記録のきっかけ**: 2026年8月3日、桑木志帆がAIG全英女子オープンで優勝し、日本人女子7人目のメジャー制覇を達成

---

## 👩 女子（7人）

| 選手       | 大会           | 年           |
| -------- | ------------ | ----------- |
| 樋口久子     | 全米女子プロ       | 1977年       |
| 渋野日向子    | 全英女子オープン     | 2019年       |
| 笹生優花     | 全米女子オープン     | 2021年・2024年 |
| 古江彩佳     | エビアン選手権      | 2024年       |
| 西郷真央     | シェブロン選手権     | 2025年       |
| 山下美夢有    | 全英女子オープン     | 2025年       |
| **桑木志帆** | **全英女子オープン** | **2026年**   |

- 2026年8月3日、桑木志帆がドイツのエスター・ヘンゼライトとのプレーオフを2ホール目で制し、米ツアー初優勝をメジャー（自身8度目の出場）で達成
- 全英女子オープンは2年連続で日本勢が優勝（2025年山下美夢有→2026年桑木志帆）

## 👨 男子（1人）

| 選手 | 大会 | 年 |
|---|---|---|
| **松山英樹** | **マスターズ・トーナメント** | **2021年** |

2026年8月時点でも、松山英樹の2021年マスターズ優勝が唯一の日本人男子メジャー制覇。以降、後続する優勝者は出ていない。
