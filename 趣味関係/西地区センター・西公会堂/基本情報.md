# 🏢 西地区センター・西公会堂

奥様（志津枝さん）が勤務されている**西地区センター**、および**西公会堂**についての記録。本人自身もイベントのボランティア（例：西地区センター納涼まつりのボッチャ担当、[[日記カレンダー/月別カレンダー/2026-07/2026-07-18]]参照）として関わっている。詳細は本人からの聞き取りにより順次追記。

---

## 📌 基本情報

| 項目 | 内容 |
|------|------|
| **西地区センター** | 奥様（志津枝さん）が勤務。**勤続20年以上**。年齢的には引退の時期だが、頼まれると断れず現役継続中（[[家族関係/妻からの告白.md]]参照） |
| **西公会堂** | 西地区センターに**隣接**。さまざまなイベントが開催される会場 |

---

## 📝 これまでに判明していること

- 妻は西地区センターに勤務し、頼まれると断れない人柄で今も現役で頑張っている（[[家族関係/妻からの告白.md]]より）
- 地区センター内では月下美人が育てられており、毎年花を咲かせている（同上）
- 本人も西地区センターの納涼まつりでボッチャ担当としてボランティア参加（2026-07-18）

---

## 💭 思い出

- 本人の言葉——**「もう20年以上に亘って地区センターの仕事を続けています」**。奥様が西地区センターで働き始めてから、すでに**20年以上**が経つという。[[家族関係/妻からの告白.md]]にある「もう年齢で引退の時期だが、頼まれると断り切れず今でも頑張っている」という本人の言葉とも重なる、長年にわたる勤続の重みが伝わる一言。
- 本人の言葉——**「隣接する公会堂ではいろんなイベントが開催されます」**。西地区センターのすぐ隣にある**西公会堂**では、さまざまなイベントが開催されているとのこと。本人自身がボッチャ担当を務めた納涼まつり（[[日記カレンダー/月別カレンダー/2026-07/2026-07-18]]参照）も、こうしたイベントの一つと見られる。
- 本人の言葉——**「中でも、アップした『ちくせん歌ひろば』に感動しました」**。数々のイベントの中でも、特に心を動かされたのが**「ちくせん歌ひろば」**という歌の集い。詳細は下記。

---

## 🎤 ちくせん歌ひろば

西地区センターの**自主事業**として開催されている、地域住民参加型の「みんなで歌う会」。キャッチフレーズは——**「大きな声で」「気持ちよく」みんなで歌おう！**

| 項目 | 内容 |
|------|------|
| **開催頻度** | ほぼ月1回（第1回：2024年3月23日／第30回：2026年8月12日——約2年半で30回を重ねる） |
| **歌唱指導** | **吉原裕作**（バスバリトン。国立音楽大学卒、二期会会員。西地区センター自主事業「ちくせん歌ひろば」講師） |
| **ピアノ伴奏** | **藤井直美**（ソプラノ。東京音楽大学・桐朋学園大学研究科修了、二期会会員。Profumo di Musica主宰） |
| **運営母体** | **Profumo di Musica**（プロフーモ・ディ・ムジカ）——吉原裕作・藤井直美が営む声楽とピアノの音楽教室（相鉄線西横浜駅・天王町駅より徒歩5分） |
| **選曲の傾向** | 唱歌・童謡・叙情歌が中心（例：春の小川、さくらさくら、案山子、朝はどこから、千の風になって、サンタルチアなど） |

### 第1回例会（2024年3月23日）の曲目
春の小川・さくらさくら・めだかの学校・荒城の月・花のまわりで・花・四季の雨・ニコニコ・モーツァルトの子守歌・小さな世界・みかんの花咲く丘・忘れな草をあなたに・リンゴの唄・夢淡き東京

### 第30回例会（2026年8月12日）の曲目
案山子・七里ヶ浜の哀歌・朝はどこから・島原の子守唄・風の盆・もういいかい・千の風になって・一杯のコーヒーから・耳をすましてごらん・サンタルチア

📎 資料：[[趣味関係/西地区センター・西公会堂/ちくせん歌ひろば先生.pdf]]（第1回例会）／[[趣味関係/西地区センター・西公会堂/第３０回１.pdf]]（第30回例会）／[[趣味関係/西地区センター・西公会堂/第30回裏面.pdf]]（第30回例会・裏面「みんなの掲示板」）／[[趣味関係/西地区センター・西公会堂/ちくせん歌ひろば先生1.pdf]]（出演者プロフィール）

### 第30回裏面「みんなの掲示板」より
参加者からの声と講師からの返信を掲載。9月24日の「ちくせん懐メロを歌う会」はコンサートではなく歌う会であること、にしくのイメージソング「にしくのうた」が会の開始前・休憩中に流れていることなどが紹介されている。

- **次回（第31回）例会**：2026年9月9日（水）12時開場・13時30分開演
  - 歌唱予定曲：里の秋・十五夜お月さん・赤とんぼ・里ごころ・老犬トレイ・月の沙漠・お月様と影ぼうし・大きな古時計・さわると秋がさびしがる・誰か故郷を想わざる・小さな喫茶店・手のひらを太陽に
- **次々回以降の予定**（全て水曜日）：10月14日・11月11日・12月9日・2027年1月13日・2月10日・3月10日
- リクエスト曲：いのちの歌・雨に咲く花・お江戸日本橋・なぎさ道・公演の手品師・子鹿のバンビ

📅 上記の日程はGoogleカレンダー（メインカレンダー）に「第31回〜第37回 ちくせん歌ひろば」として登録済み（第32回以降は時刻未確定のため、前回までの例に基づく想定時刻で仮登録）。

本人の言葉——**「第1回でも春の小川、さくらさくらの資料が全てあります」**。第1回例会の資料PDFには、表紙の曲目一覧だけでなく、**春の小川・さくらさくら等、掲載曲すべての楽譜（歌詞・メロディー譜付き）が収録**されている。実際に会場で配られた、そのまま歌える完全な資料であることがわかる。

本人の言葉——**「膨大な資料です」**。1回の例会あたり10〜14曲分の楽譜が収録され、それが**第1回から第30回まで、2年半にわたり毎回作成・配布**されてきたことになる。単純計算でも300曲分以上の楽譜が積み重なっている計算で、ちくせん歌ひろばの運営の丁寧さと継続の重みを、本人はあらためて実感した様子。
