# 🚌 西区シニアバス旅行

**西区シニアクラブ連合会**（[[趣味関係/グランドゴルフ関係/基本情報|平睦・寿伍録クラブ]]が加盟する同連合会）が主催する、日帰り親睦バス旅行。本人からの聞き取り・案内チラシをもとに順次追記。

## 🍊 令和8年度 秋の旅行（2026年11月30日）

25周年東京ランタンフェスティバル・イルミネーション／三芳村みかん狩りと漁師料理海鮮昼食

| 項目 | 内容 |
|------|------|
| **出発日** | 令和8年11月30日（月） |
| **旅行代金** | ¥11,000（添乗員付） |
| **集合・出発** | 改めて代表者へ案内書を送付予定 |
| **応募締切** | 10月24日（土） |
| **取消料** | 出発日10日前〜2日前：30％／前日：50％／当日：100％ |

### コース
西区(10:00)→アクアライン→海ほたるPA（休憩）→**漁師料理たてやま**（海鮮昼食）→房総の蔵・お百姓市場（農産物・買物）→**三芳村**（みかん狩り・園内食べ放題）→**東京ドイツ村**（25周年東京ランタンフェスティバル）→アクアライン→西区(19:30)

※道路状況等によりコースの順番が変わる場合あり

### 特典
- 房総みかん狩り園内食べ放題
- 房総名物イカメンチ1個お土産

### 注意事項
- 雨具・健康保険証・常備薬は各自持参
- 団体行動のため集合時間は厳守
- 当日バス車内でも集金可（クラブ事にまとめて協力するよう案内）

### 🌺 群馬県館林市：つつじが岡公園（写真で確認できた立ち寄り先）
「つつじが岡公園入園記念」の看板があり、白・ピンク・赤・紫と色とりどりのツツジが満開。本人が赤いツツジを背景に自撮りし、殿様・お姫様風の顔はめパネルでも記念撮影。志津枝さんともう一人の女性は、ピンクのツツジの前のベンチで記念写真。

近くの川（鶴生田川とみられる）には無数の鯉のぼりが掲げられ、水面に色とりどりの姿が映り込む光景も撮影——**館林市名物「鶴生田川鯉のぼりの里まつり」**（例年4月中旬〜5月上旬開催）とほぼ確実に重なる時期。

### 💜 栃木県足利市：あしかがフラワーパーク（推定）
大藤（藤）が満開のトンネル状の棚と、池に浮かぶ花の島（デイジー・チューリップ等）に多くの来園者。足利市を代表する観光地で、CNNの「世界の夢の旅行先」にも選ばれた大藤で知られる**あしかがフラワーパーク**とほぼ断定できる内容。

### ❓ 埼玉県羽生市周辺：立ち寄り先未確定（本人に要確認）
本人の記憶：「**シラサギが群れをなして**」いたとのこと。写真でも木々にシラサギが複数羽とまっている様子が確認でき、単発ではなく**コロニー（集団営巣地）のような群れ**だった可能性が高い。銀色のドーム（天体観測施設・プラネタリウムのような建物）が写った写真も同じ立ち寄り先とみられる。羽生市内の野鳥の楽園・調節池のような場所か、往復途中の施設と思われるが、**具体的な施設名は写真からは特定できず**。心当たりがあれば教えてください。

## 📝 これまでに判明していること

- 春・秋の年2回、日帰りを中心にバス旅行が計画されている
- 西区内各地区（第一〜第六地区）から1台ずつ、計6台のバス編成という組織的な規模
- 旅行取扱は例年（少なくとも今回）株式会社新中央ツーリストが担当
- 2026年春（4/28）は埼玉県羽生・群馬県館林・栃木県足利市を巡るツツジ・フジの花見コース。館林は「つつじが岡公園」＋「鶴生田川鯉のぼりの里まつり」、足利は「あしかがフラワーパーク」の大藤とほぼ特定（羽生の立ち寄り先のみ未確定）
- 2026年秋（11/30）は「東京ランタンフェスティバル・イルミネーション」と「三芳村みかん狩り・海鮮昼食」を組み合わせた房総方面日帰りコース
