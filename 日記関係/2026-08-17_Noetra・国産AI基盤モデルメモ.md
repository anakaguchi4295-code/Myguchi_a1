# Noetra（ノエトラ）・国産AI基盤モデル関連企業メモ

## Noetraとは

**Noetra株式会社**は、日本発の**マルチモーダル基盤モデル**（ロボット・フィジカルAIの基盤となるAIモデル）を研究開発する企業。いわゆる「**ソブリンAI（国産・自国主権AI）**」戦略の象徴的プロジェクトで、海外の巨大テック企業（OpenAI・Google・Meta等）に依存しない日本独自のロボット向けAI基盤モデルの確立を目指す。

### 基本情報

| 項目 | 内容 |
|------|------|
| 設立 | 2026年1月7日（旧社名「株式会社日本AI基盤モデル開発」から2026年6月1日に社名変更） |
| 本社 | 東京都渋谷区 |
| 代表者 | 丹波廣寅（代表取締役社長） |
| 事業開始 | 2026年7月1日 |
| 事業内容 | 国産マルチモーダル基盤モデルの研究開発、モデル開発用インフラの検討・整備 |
| 開発規模 | GPU約27,500基規模のインフラを整備し、2030年度に「実世界対応」（ロボット制御等への実装）を目指す |

## 政府支援

- 経済産業省・NEDO（新エネルギー・産業技術総合開発機構）の「Generative AI基盤モデル」関連事業として選定。
- **2026年度分：開発委託費3,873億円**を支援。
- **5年間で最大1兆円（約23億ドル）規模**の公的支援方針が報じられている。
- 2030年度までに「実世界対応」の国産フィジカルAI基盤モデル確立を目標とする国家プロジェクト的な性格が強い。

---

## 投資判断で注意したい点

- Noetra自体は**非上場**のプロジェクト会社であり、直接の株式投資対象ではない。投資対象として見る場合は、出資している上場企業（ファナック・東京エレクトロン・日立・富士通等）を通じた間接的な関わりになる。
- 44社の正式な出資比率・資本構成は非公表。報道ベースの情報のみで、今後の公式発表で内容が変わる可能性がある。
- 国主導の巨額補助金プロジェクトである点で、政策継続性（政権交代・予算編成の影響）に業績インパクトが左右されやすい性格を持つ（[[日記関係/2026-08-16_シスルナ・宇宙関連企業メモ.md]]のアルテミス計画と同様の構図）。
- GPU調達（27,500基規模）はNVIDIA等半導体需要にも波及しうるテーマ。
