# キオクシアホールディングス（285A）— 上場前〜現在までのまとめ

## 📜 上場前の沿革

| 時期 | 出来事 |
|------|--------|
| 1980年 | 東芝・舛岡富士雄氏がNOR型フラッシュメモリを発明 |
| 1986年 | 同氏がNAND型フラッシュメモリを発明（キオクシアのルーツ） |
| 2015年 | 東芝で会計不正が発覚 |
| 2017年3月 | 米原子力子会社ウェスチングハウスが破綻し、東芝が債務超過に転落 |
| 2017年6月 | 東芝、半導体メモリ事業の売却先として産業革新機構・日本政策投資銀行・ベインキャピタル・SKハイニックスによる日米韓連合を優先交渉先に選定 |
| 2017年9月 | ベインキャピタル主導の買収目的会社「Pangea」と株式譲渡契約締結 |
| 2018年6月1日 | 東芝が半導体メモリ事業を分社化した「東芝メモリ」の全株式を約2兆円でPangeaへ譲渡（上場廃止回避のための「虎の子」事業売却） |
| 2019年10月1日 | 「東芝メモリホールディングス」→「キオクシアホールディングス」に社名変更 |
| 2020年 | 一度IPOを申請するも市況悪化等により延期（撤回） |

**背景メモ**：東芝本体の経営危機（会計不正＋ウェスチングハウス破綻）により、稼ぎ頭だったメモリ事業を手放さざるを得なかったという「身売り」の経緯が上場前史。ベインキャピタル連合の傘下に入って以降、コロナ禍でのIPO延期を経て2024年末にようやく上場。

## 🚀 IPO（新規上場）概要

| 項目 | 内容 |
|------|------|
| 上場日 | 2024年12月18日 |
| 市場 | 東証プライム市場 |
| 証券コード | 285A |
| 主幹事 | 三菱UFJモルガン・スタンレー証券 |

上場直後は半導体市況の弱さ（NAND価格低迷）もあり、派手な滑り出しではなかった。

## 📈 上場後の株価推移

- 2025年末終値：約10,435円
- 2026年1月6日：年初来安値 10,945円
- 2026年6月22日：年初来高値 **112,700円**（半年で約10倍、IPO公募価格からは約75倍）
- その後は乱高下し、2026年8月時点で高値からほぼ半値近辺まで調整（アナリスト平均目標株価111,431円に対し上値余地+107%とされる水準＝2026-08-15時点の実勢はおおよそ5万円台前半とみられる）
- 2026年8月上旬、決算がやや市場予想を下回ったにもかかわらず自社株買い発表を好感して3日続伸・一時+12%という荒い値動きも

**背景**：生成AI向けデータセンター需要によるNAND型フラッシュメモリの急激な需要増・価格上昇（ASP上昇）が株価急騰の最大要因。半導体市況・AI投資サイクルへの感応度が非常に高い銘柄。

## 🔍 現状・今後の注目点

- **強気材料**：生成AI向けデータセンター需要が構造的に拡大しており、NANDメモリのASP上昇局面が続く限り増益基調は持続しやすい。大型自社株買いによる需給改善期待も。
- **懸念材料**：市場予想比での「下振れ」が出るなど期待値のハードルが非常に高い。株価が半年で10倍→高値から半値近くまで急落するなどボラティリティが極めて大きい。中国メーカー台頭による中長期的な価格競争リスク、NAND市況循環（半導体特有の好不況サイクル）への警戒も必要。
- **アナリスト評価**：2026年8月15日時点でコンセンサスは「買い」、平均目標株価は111,431円（当時株価から+107%の余地）と強気姿勢が目立つ。
