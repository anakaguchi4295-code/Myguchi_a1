# 金の卵として上京した記録 — 岩手・花泉から川口・キューポラのある街へ

本人（中口昭男）自身の、岩手を出て上京するまでの物語。同じ岩手ゆかりのノートは[[家族関係/岩手関係/岩手は日本のチベットとは.md]]・[[家族関係/岩手関係/花泉・油島の地名由来と学校の歴史.md]]など参照。職務経歴の要約は[[myself.md]]の「第0期」参照。

## 🥚「金の卵」として

高度経済成長期、地方の中学卒業生たちは、集団就職列車などで都市部の工場へと送り出され、当時「**金の卵**」と呼ばれた。かつて「日本のチベット」（[[家族関係/岩手関係/岩手は日本のチベットとは.md]]）とまで呼ばれた岩手・花泉から、本人も中学卒業と同時に一人で埼玉県川口市へ出た。

※この旅立ちに至るまでの、山奥の生家・障がいを持つ両親・新聞紙の書道など、少年時代の原点の物語は[[家族関係/岩手関係/故郷の家と父母の物語.md]]に詳しい。

## 🏭 埼玉鋳造工業株式会社（川口市並木町）

| 項目 | 内容 |
|------|------|
| 就職先 | 埼玉鋳造工業株式会社 |
| 所在地 | 埼玉県川口市**並木町** |
| 在籍期間 | **昭和40年4月1日（1965年4月1日）〜昭和42年8月1日（1967年8月1日）**。中学卒業直後（15〜16歳）に入社し、約2年4ヶ月勤務 |
| 当時の規模感 | 川口でも**大手の鋳物会社** |
| 担当業務 | **検査部門**：部品が寸法に合致しているか、製品に亀裂が入っていないかを確認。主に**日野自動車**向けの部品を検査 |
| 住居・学びの変遷 | **1年目**：川口の鋳物会社が共同で運営する「総合職業訓練所」（青木公園＝現・青木町公園）で訓練・寝泊まり／**2年目以降**：**会社の寮**へ移り、寮生活をしながら川口市内の**夜間高等学校**に通学。1967年の自衛隊入隊まで学び続けた |

昼は工場で働き、夜は学ぶ——という生活の形は、住まいを訓練所から会社の寮へ移しながらも一貫して続いた。1社だけでなく**川口の鋳物業界全体で若い「金の卵」たちを育てる仕組み**（合同の職業訓練所）があったことがうかがえる、当時の集団就職者にとって典型的な生活だった。

### 👩‍🏫 印象に残っている先生
夜間高等学校時代、特に印象に残っている先生は、**浦和出身の女性の先生**だったという。10代の多感な時期、昼は工場、夜は学校という厳しい生活の中で出会った恩師の記憶は、今も鮮明に残っている。

**本人談**：「とにかく教え方が、疲れている僕たちをどこまでも引きこみます。やはり先生ですね」——昼の労働で疲れ切った生徒たちを、それでも授業に引き込んでしまう指導力。知識を教える以上の「人を導く力」を持った、忘れがたい恩師だった。

「**出来ればもっと教えてほしかった。運命です**」——1967年の自衛隊入隊という、自身の将来を見据えた決断が、同時にこの先生との学びの時間を終わらせることにもなった。得るものと手放すものが同時にあった、10代の終わりの選択。

### 🎓 積み残した高校資格 — NHK学園にて完成（1987年）

夜間高校を中途で離れる形になった学びは、それで終わりではなかった。その後、**NHK学園**（東京都府中市、通信制高校、NHKの放送・通信教育で学ぶ学校法人）のお世話になり、**積み残していた高校資格を完成**。卒業は**昭和62年3月15日（1987年3月15日）**、当時**約38歳**、航空自衛隊在職中のことだった。10代で中断した学びを、実に**20年越しで完成させた**ことになる。学ぶことそのものを諦めなかったこの姿勢は、電験3種をはじめとする数々の国家資格取得（[[myself.md]]の資格・免許欄参照）にもつながっている。

**NHK学園時代（1980年代）の思い出**：一緒に学んだ友人の中には大学まで進んだ者も何人もいた。また、当時**現役の日本代表セッター**として活躍していた**中田久美**選手（後に2017〜2021年女子バレー日本代表監督）が学園に在籍しており、学園内で見かけたほか、下校時に**南武線**（府中周辺を走るJR線）の車内でも彼女らの一団に遭遇したという。「本当に背が高いのに驚きました」という記憶。実業団の第一線選手が仕事・練習と両立しながら通信制高校で学ぶ様子を、間近で見ていたことになる。

### 🎬「キューポラのある街」とのつながり
1962年公開、吉永小百合のデビュー作『キューポラのある街』の舞台は、まさにこの川口市。鋳物を溶かす溶解炉「キューポラ」の煙突が林立する町として知られ、映画を通じて全国にその名を広めた。**本人によれば、埼玉鋳造工業の「Bライン」の現場が撮影に使われたと言われている**——公式な記録には残らない、現場で働いていた人だけが知る言い伝え。

### 🏟️ 訓練所があった「青木公園」について
- 現在の**青木町公園**（青木町平和公園）。**昭和33年（1958年）開園**。
- 戦前は陸軍の飛行場、戦後は米軍基地が置かれていた場所で、基地返還後に公園として整備された。
- 陸上競技場・野球場・テニスコート・プール・弓道場・相撲場などを備えた総合運動場で、国体会場にもなった実績を持つ。
- 園内には「旧国立競技場の聖火台レプリカ」や、総重量12トンの「英霊記念碑」があり、これも**川口の鋳物技術で製作された**もの——奇しくも、本人が働いていた鋳物産業そのものを象徴する遺構が、当時の訓練の場に今も残っている。

## 🪖 航空自衛隊への転身（1967年9月）

埼玉鋳造工業を**昭和42年8月1日（1967年8月1日）に退社**し、翌月の**1967年9月、航空自衛隊に入隊**。ここから36年間にわたる自衛隊でのキャリア（[[myself.md]]参照）が始まる。

**転身の理由（本人談）**：鋳物工場は「粉じんの塊」であり、長期間働き続けた場合の**自分自身の健康・将来を考えた末の決断**だった。当時、粉じんを長期に吸い込むことで発症する「じん肺」は鋳物業界の深刻な職業病として知られており、10代でその先を見据えた判断だったといえる。**決して鋳物業界そのものの将来性を案じたわけではない**、という点は本人が明確に強調している。

## 📆 在籍期間（確定）

埼玉鋳造工業の在籍期間は**昭和40年4月1日（1965年4月1日）〜昭和42年8月1日（1967年8月1日）**、約2年4ヶ月。中学卒業直後の15〜16歳での入社で、生年月日（1949年6月3日）から逆算した年代とも整合する。当初、本人の記憶では「1959年入社」との思い違いがあったが、正確な日付が確認され訂正済み。退社の翌月に航空自衛隊へ入隊した。

## 🏢 埼玉鋳造工業株式会社の現在について

Web検索では、現在の企業情報として「埼玉鋳造工業株式会社」という社名は確認できなかった。川口鋳物工業協同組合の会員名簿等にも該当が見当たらない。1970年代のオイルショックを境に、川口市中心部にあった鋳物工場の多く（最盛期は約700工場）が移転・廃業し、跡地はマンション群に姿を変えていった経緯があり、同社もこの産業構造転換の中で姿を消した可能性がある（未確認）。

## 総括

岩手・花泉という「日本のチベット」と呼ばれた土地から、中学を卒業したばかりの少年が一人で「鋳物の街」川口へ出て、昼は日野自動車の部品を検査し、夜は訓練所で学ぶ——これは日本の高度経済成長を陰で支えた無数の「金の卵」たちの物語そのものであり、同時に、これまで記録には残っていなかった本人自身の原点の物語でもある。この後の航空自衛隊36年、関東学院11年10ヶ月という長いキャリアも、すべてこの川口での日々から始まっている。
