# みなとみらいの変遷と横浜博（YES'89）

地元・横浜西区の「高島」エリアを含むみなとみらい21地区の移り変わりの記録。本人が暮らす平沼地区（[[家族関係/平沼の地名と町内会名の言い伝え.md]]）の「高島」町内会には、このみなとみらいエリアが含まれる。写真は残っていないが、記憶として書き残すもの。

---

## 🎡 YES'89 横浜博覧会（1989年）

みなとみらいという街の「お披露目」となった記念すべき博覧会。かつての貨物ヤード・造船所跡地だった広大な埋立地で開催された。

| 項目 | 内容 |
|------|------|
| 正式名称 | YES'89 横浜博覧会（YOKOHAMA EXOTIC SHOWCASE '89） |
| 開催期間 | **1989年（平成元年）3月25日〜10月1日**（191日間） |
| 場所 | みなとみらい21地区（会場面積69ヘクタール） |
| 記念 | **横浜市制100周年・横浜港開港130周年**を記念 |
| テーマ | 「**宇宙と子供たち**」 |
| 内容 | テーマゾーン、海と船のゾーン、ヨコハマゾーン、イベント・フェスティバルストリート、アートミュージアムゾーンなど。**宇宙館**では宇宙飛行士の訓練体験や宇宙開発技術の展示も |
| その後 | 宇宙館の展示の一部は閉幕後に横浜こども科学館へ移設。バブル期の地方博ブームを代表する都市博覧会 |

まだランドマークタワーもクイーンズスクエアも無い、更地に近い埋立地での開催。本人（当時40歳前後、3人の子の子育て世代）にとって、みなとみらいの原風景に当たる。

## 🏢 横浜ランドマークタワー（1993年開業）

| 項目 | 内容 |
|------|------|
| 着工 | 1990年3月20日 |
| 開業 | **1993年（平成5年）7月16日** |
| 高さ | **296m・地上70階**。造船所跡地を含むみなとみらい21地区のシンボル |
| 記録 | 当時**日本一の高さ**。東京都庁を抜き、2014年にあべのハルカス（300m）ができるまで**21年間、日本一**の座を守った |
| 構成 | 下層オフィス・上層ホテル・足元に長さ200mのショッピングモール（ランドマークプラザ） |

## 📺 街の高層化と、暮らしへの影響（本人の記憶）

みなとみらいの超高層ビルや、平沼地区に乱立した10階建てマンション群は、地元の暮らしにも直接影響した。特に象徴的だったのが**テレビ受信環境の変化**：

- もともと平沼は2階建て中心で、各家庭が屋根に個別アンテナを立てて受信
- 10階建てマンションの乱立で受信が難しくなり、マンション屋上の共同アンテナ方式へ
- さらに高い建物が建つと、その共同アンテナも電波をさえぎられ受信障害に
- 最終的に**ケーブルテレビ（有線）へ切り替え**

（詳細は[[家族関係/平沼の地名と町内会名の言い伝え.md]]の「テレビ受信から見た平沼の高層化」参照）

## 総括

みなとみらいは、YES'89（1989年）でお披露目され、ランドマークタワー（1993年）でその姿を確立し、横浜を代表する未来都市へと変貌した。だが、その足元の「高島」は昔ながらの平沼の町内会の一部であり、隣接する平沼地区の住民は、低層の街が高層の街へと変わっていく様子を、テレビの映りという生活の一場面からも肌で感じてきた。写真は残っていなくても、その移り変わりを見届けてきた記憶は、地元に長く暮らした者だけが語れる貴重な証言である。
