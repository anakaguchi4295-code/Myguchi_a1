# わが家の始まりの物語と平沼の地域医療

本人（中口昭男）夫妻の結婚にまつわるご縁と、地元・平沼の地域医療の記憶。人と人とのつながりの中で受け継がれてきた、若い世代はほとんど知らない大切な物語。地元の地名・町内会の言い伝えは[[家族関係/平沼の地名と町内会名の言い伝え.md]]、地元の氏神様は[[家族関係/水天宮平沼神社.md]]参照。

---

## 💒 わが家の始まりの物語 — 結婚のご縁

### 挙式・披露宴
| 項目 | 内容 |
|------|------|
| 挙式 | **伊勢山皇大神宮**（横浜総鎮守・「関東のお伊勢さま」、横浜市西区宮崎町の高台。明治3年創建、天照大御神を祀る） |
| 披露宴会場 | **桜木町駅近くの「ゴールデンセンター」**（当時の結婚式場・会館。その後、名称が変わり現存しない） |

### お世話になった丸山様
- 結婚に際して、**丸山様**に大変お世話になった。
- 丸山様は、**「ふじ」さんの叔母（おばちゃん）の知り合い**という間柄。昔ながらの、親戚とその知り合いという「人のご縁」を通じてお世話になった。
- **丸山家の先代のお名前は、伊勢山皇大神宮の石段（参道）に刻まれている**（社殿・参道の造営に寄進した証）。本人は石段を上るたびにそのお名前を目にし、結婚式のご縁とあわせて感謝の念を抱いている。

---

## 👶 助産婦「ふじ」さん — 平沼の命を支えた人

- 「ふじ」さんは、一説によると**助産婦（産婆さん）**で、**平沼の人たちの子供を取り上げ、世話をしてきた**方だという。
- 昔の助産婦は、お産を助けるだけでなく、その後の子育ての相談にも乗り、地域の母子を見守る「街の命の守り手」だった。
- **今でも、ふじさんにお世話になった人から、本人が声をかけられる**ことがある。何十年経っても地域の人々が感謝を忘れずに語り継いでいる、それだけ平沼の人々に慕われ大切にされてきた証。

---

## 🏥 平沼の地域医療 — 植松病院（現・コンフォート病院）

| 項目 | 内容 |
|------|------|
| 場所 | 本人の**家のすぐ裏手（家の後）** |
| 昔 | **植松病院**。院長は**小学校の学校医**も務め、平沼の子供たちの健康診断・保健指導を担い、地域の子供みんなの体を診ていた |
| ふじさんとの関わり | 助産婦のふじさんは、**この植松病院にも関わっていた** |
| 現在 | **コンフォート病院**に。名前と姿は変わっても、その場所は昔も今も「地域の医療を担う場所」であり続けている |

**平沼の「命と健康を支える仕組み」**：植松病院（院長＝学校医）と助産婦ふじさんが連携し、赤ちゃんの誕生から子供の成長、日々の健康までを地域ぐるみで見守っていた。大きな総合病院ではなく、「街の中に顔の見える医療があった」時代の姿。その全部が、本人の家のすぐ近くで営まれていた。

## 総括

一つの結婚のご縁をたどると、丸山様、その縁の「ふじ」さん、そして平沼の命を支えた助産婦や地域の病院へとつながっていく。人が遺した善き行いが世代を越えて感謝され続ける——伊勢山皇大神宮の石段に刻まれた丸山様の先代への感謝も、今も街で語られるふじさんへの感謝も、根は同じ。街並みが変わり、病院の名も変わっても（植松病院→コンフォート病院）、人と人とのご縁と、それを覚えて感謝する心は受け継がれていく。これは、子や孫に伝えたい「わが家の始まりの物語」であり、昭和の平沼の地域医療の貴重な証言でもある。
