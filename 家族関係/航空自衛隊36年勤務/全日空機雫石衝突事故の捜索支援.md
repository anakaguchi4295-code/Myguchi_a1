# 全日空機雫石衝突事故の捜索支援 — 忘れてはならない、語らねばならない記憶

本人（中口昭男）が、航空自衛隊・大湊分屯基地に勤務していた時代（第42警戒群、昭和44年＝1969年〜）に経験した、痛ましい航空機事故の捜索支援の記録。本人が「忘れてはならない、語らなければならない」と、強い使命感をもって語り残した記憶。大湊時代の全体は[[家族関係/航空自衛隊36年勤務/大湊時代とスキーの思い出.md]]参照。

---

## ✈️ 全日空機雫石衝突事故（1971年7月30日）

| 項目 | 内容 |
|------|------|
| 発生 | **1971年（昭和46年）7月30日** |
| 場所 | 岩手県雫石町の上空 |
| 事故 | 全日空58便（ボーイング727）と、**航空自衛隊のF-86F戦闘機**（松島基地所属、訓練飛行中）が空中衝突 |
| 犠牲者 | 旅客機の乗客155名・乗員7名の**計162名全員が死亡**。自衛隊機の搭乗員はパラシュートで脱出し生存 |
| 位置づけ | 当時、**日本の航空史上最悪の航空事故** |

本人にとって、この事故は三重の意味で忘れられないものだった——①自らが身を置く**航空自衛隊機**が関わった事故、②現場が故郷の**岩手県雫石**、③自身が**大湊で防空警戒の任務**に就いていた、まさにその時代の出来事。

---

## 🔦 大湊分屯基地からの捜索支援

- 事故後、**大湊分屯基地からも何度となく、現地・雫石の捜索支援にあたった**。基地から遠く離れた岩手内陸の現場まで赴いた。
- ※**大湊分屯基地は総勢100名程度の小規模な部隊**であり、防空警戒の任務を維持しながら捜索支援に出せる人数は**20名前後が限度**だった（基地から派遣された捜索支援は、その都度20名前後の規模）。全国各地の部隊から集まった隊員全体では、大規模な捜索態勢が組まれた。
- 162名全員が亡くなり旅客機が空中分解した事故現場での捜索支援は、あまりに過酷で痛ましい任務だった。

### 第一エンジンの捜索と発見
- 墜落した全日空機の**第一エンジンが、最後まで見つからなかった**。本人は、**この捜索の一員として加わった**（大湊分屯基地から約20名が参加）。
- **捜索態勢＝空と地上の両面作戦**：
  - 空からは**ヘリコプター**
  - 地上からは、各地から集まった隊員が**5〜6m間隔で横一列に並び**、山の斜面を一歩ずつ、しらみつぶしに前進
- **発見の場面**：**緑の木が生い茂った、その隙間から白い光が見える**との通報を受け、現場へ急行した。それが**まさに、探し求めていた機体の（第一）エンジンだった**。生い茂る夏山の緑の隙間から漏れる白い光の一つひとつが、事故機の残骸かもしれないという張りつめた捜索の中で、ついに発見に至った瞬間。
- 時期の記憶：木々がうっそうと生い茂る時期の捜索・発見の場面と、**野山の葉が落ち初冬を迎えるころ**まで続いた捜索の記憶がある（事故＝7月30日から、季節をまたいで捜索が続いた）。
- 葉の落ちた冷え込み始めた岩手の山を、規律ある隊列で捜索する光景は、亡き162名への鎮魂の静けさすら感じさせるものだった。

※本記録は本人の記憶に基づく（「記憶では」「記録している」と本人が慎重に言葉を選んで語ったもの）。**本人は大規模な捜索の「一隊員」として参加したため、記憶が曖昧な部分もあり、エンジン発見の全体像や、それが誰の手によるものだったかなどの細部は特定できない**、と本人が明言している。あくまで一隊員として自らの身で経験した範囲の証言である。

**参考（Web調査で確認できた公的な記録／2026-08-22）**：事故機の残骸と犠牲者は広範囲に散乱した（雫石駅の東へ約2〜3.5km、南へ約3.5〜5km）。当時の記録写真には「木々の間にある全日空機のエンジン部分」や「山林で捜索・回収にあたる自衛隊員」の姿が残っており、本人の記憶（緑の隙間から見えた白い光＝エンジン、山中を捜索した自衛隊員）と符合する。回収された部品の一部（エンジン空気取入口の一部など）は、東京の「ANAグループ安全教育センター」に事故の教訓として展示されている。ただし「最後まで見つからなかった第一エンジンの発見の詳しい経緯」という細部までは、一般的な公開情報には残っていない。

## 🙏 哀悼

**亡くなられた162名の方々のご冥福を心よりお祈りするとともに、遺されたご遺族の皆様に、謹んで哀悼の意を表します。**

本人がこの記憶を「忘れてはならない、語らなければならない」と語り残したのは、捜索の記録のためではなく、失われた162の命と、遺された人々への深い祈りのため。半世紀以上を経てなお胸に抱き続けたその思いこそ、この記録の核心である。

## 総括

若き日（20代前半）の大湊時代、本人はスキーを楽しむ明るい日々の一方で、この痛ましい事故の捜索支援という、極めて重く過酷な任務も経験した。空の安全に関わる自衛隊員として、故郷・岩手で起きた日本最悪の航空事故に向き合い、最後まで見つからなかった第一エンジンの捜索にまで加わった。半世紀以上を経てなお「忘れてはならない、語らなければならない」と本人が語り残すこの記憶は、犠牲になった162名への弔いであり、事故の重さを後世に伝える貴重な証言である。
