# 横浜のスポーツイベントを支えたボランティアの記録

本人（中口昭男）が長年にわたり最前線で支えてきた、横浜の大規模スポーツイベントのボランティア活動の記録。職務経歴・資格等は[[myself.md]]、地元・平沼／みなとみらいの記録は[[家族関係/平沼の地名と町内会名の言い伝え.md]]・[[家族関係/みなとみらいの変遷と横浜博（YES89）.md]]参照。

---

## 🏃 背景 — スポーツ推進員として

- **横浜市スポーツ推進員（旧・体育指導員）**として活動。市長委嘱による公的な社会貢献で、**20年表彰（功績表彰）**を受けた。
  - **委嘱期間：平成9年〜平成25年（1997〜2013年）、2年ごとの委嘱（更新制）**
  - **実際の活動終了：平成27年（2015年）3月**
  - 20年前後の長期にわたる地域貢献
- この立場を軸に、横浜市の大規模スポーツイベントの運営支援に長年携わった。

## 🏅 支援してきた大会

### ① 横浜国際女子駅伝
| 項目 | 内容 |
|------|------|
| 大会 | 1983年〜2009年、毎年2月第4日曜開催。**27回続いた国際大会**。2002年までは横浜スタジアム発着、2003年以降は赤レンガ倉庫〜八景島シーパラダイス折り返し |
| 任務 | **沿道のコース設定と警備・ガード**。観客・車両がコースに入らないよう見張る、選手の安全を預かる最前線 |
| 支援体制 | **横浜市18行政区の各団体**が総がかりで支え、本人は西区（平沼を含む地区）の団体の一員として参加 |
| 記憶 | **小雪の舞う中で開催された大会**もあった。2月の真冬、選手は走れば温まるが警備側は寒さの中に立ち続ける。かじかむ中でも持ち場を守った |

### ② 世界トライアスロンシリーズ横浜大会（山下公園）
| 項目 | 内容 |
|------|------|
| 大会 | 山下公園発着。**2009年（平成21年）初開催**（横浜開港150周年記念事業として）。世界のトップ選手が集う国際大会。パラトライアスロンの聖地 |
| 任務 | **カラーコーンでのコース設定** と、**5mほどの間隔で立ち並び観客がコースに入らないよう規制**する警備 |
| 参加時期 | 2009年の初開催以降、スポーツ推進員として活動していた**平成27年（2015年）3月頃までの間に何回か参加** |

### ③ 横浜八景島トライアスロンフェスティバル（八景島）
| 項目 | 内容 |
|------|------|
| 大会 | 横浜・八景島シーパラダイス。子ども〜大人が楽しむ市民参加型大会 |
| 任務 | 同上（コース設定・観客規制） |
| **特に苦労した点** | **鉄人レースと、八景島シーパラダイスの一般観光客とが同じ空間に混在**する中でのイベント。レジャー目的の観光客（子ども連れも多い）がコース周辺を行き交うため、「選手の安全確保」と「観光客の通行への配慮」の二重の調整が必要で、通常の駅伝警備とは比べものにならないほど神経を使い、大変苦労した |

### ④ 横浜マラソン（活動の締めくくり）
| 項目 | 内容 |
|------|------|
| 大会 | 1981年初開催の歴史ある市民マラソン。1992年にハーフマラソン化（長年「横浜ハーフマラソン」として親しまれた）、2015年にフルマラソン化。スタートは横浜ランドマークタワー前、みなとみらい・赤レンガ・首都高湾岸線を巡るコース |
| 参加 | **フルマラソン化後（2015年〜）の支援を2回**務め、これをもって長年のスポーツイベント支援ボランティアを**引退** |

## 総括

自衛隊での36年間の防空・警戒任務に始まり、退官後も横浜の街のスポーツイベントを最前線で支え続け、横浜マラソンで有終の美を飾って引退した。女子駅伝の小雪の寒さも、トライアスロンの観客規制の緊張も、じっと持ち場を守り続ける——**「人々の安全と大会の成功を、目立たない最前線で守り続けた」**という一貫したテーマが、本人の生き方を貫いている。華やかな主役ではなく、それを支える縁の下の力持ちに徹した、誇るべき社会貢献の記録。写真は残っていないが、その場に立ち続けた本人だけが語れる貴重な証言である。
