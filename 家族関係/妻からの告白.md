# 妻からの告白

本人（中口昭男）が語る、奥様からの「告白」にまつわる思い出。詳細は本人からの聞き取りにより順次追記。

---

## ✅ 次のアクション

- **明日、地区センターを訪ねて、月下美人の分けてもらえるか聞く**（本人予定）。月下美人栽培への挑戦の第一歩。結果は追って追記予定。
- **新しい情報 — 「地区センターの花はもう頼りないようです」**：本人の言葉。地区センターの月下美人は、株の状態があまり良くない（弱っている）様子とのこと。もし株が弱っているなら、そこから健康な挿し木を分けてもらうのは難しいかもしれない。**隣家の月下美人を主な入手先として考える**のが現実的か。地区センターの株については、無理に挿し木をもらうより、まずは様子を見るのが良さそう。
- **「4、5年前の実態が見たいです」**：本人の言葉。地区センターの月下美人が今は頼りない様子だが、**4、5年前はどんな状態だったのか、その頃の姿を見てみたい**という。妻が見せてくれた「毎年咲いている写真」の中に、元気だった頃の姿が残っているかもしれない。今の弱った状態と、数年前の元気だった頃の姿を見比べることで、**株がどう変化していったのか**、栽培の参考にもなりそうだという本人の探究心の表れ。
- **「妻の意見を聞きます」**：本人の言葉。4、5年前の様子や、明日の地区センター訪問の進め方について、まずは**妻に相談する**という。地区センターで働く妻だからこそ知っている事情や、古い写真の在りかなど、妻の意見を大切にしながら進めていく姿勢。

---

## 📝 思い出

- **当時、隣の家には夫婦と3人の子供が住んでいました**。本人の言葉。この隣家の存在が、後に続く「妻からの告白」の話の背景・伏線になっていると見られる。
- **時系列の確認 — 「隣の月下美人の花が最初です」**：本人の言葉。硫黄島・隣家・地区センターと3つの月下美人が語られてきたが、本人の記憶の順序としては**隣家の月下美人がすべての始まり**だった。隣家に誘われてその花を見たことが、地区センターの写真や硫黄島の記憶を呼び起こし、月下美人をめぐる一連の思索（「人生一夜とは」「花の命とは」）へとつながっていった——**隣人のさりげない一言「今晩花が咲くから見て」こそが、この物語すべての出発点**だったことが、ここで確認されている。
- **「今晩花が咲くから見て」と誘われた、隣の月下美人**：本人の言葉——**「平屋建ての庭先に、『今晩花が咲くから見て』と言われ、隣の月下美人の花が勢いよく咲いていました」**。隣家（平屋建て）の庭先で育てていた**月下美人**——一夜だけ花を咲かせる幻想的な花——が、その晩まさに咲こうとしており、隣人から「見て」と誘われた。行ってみると、月下美人の花が勢いよく咲いていた。硫黄島の夜に見た月下美人の群生（[[家族関係/航空自衛隊36年勤務/気象群時代の記録.md]]参照）と同じ花が、今度はご近所付き合いの温かい一場面として登場する——本人が自然の織りなす一夜限りの美しさに何度も心を動かされてきたことがうかがえる。
- **妻の証言 — 「白ではなく赤い花でした」**：ここで話に食い違いが生じる。**妻の証言によれば、隣の月下美人は白ではなく赤い花だった**という。一般的に月下美人は純白の花を咲かせることで知られる（硫黄島の月下美人も「白い花」と記録されている）。赤い花だったという妻の記憶は、通常の月下美人とは異なる品種（赤花系の交配種など）だったのか、あるいは本人と妻とで記憶の色合いが食い違っているのか——この「白か赤か」という食い違いこそが、後に続く「妻からの告白」の核心に関わってくると見られる。
- **本人の記憶の再確認 — 「硫黄島の月下美人は白い花だった」**：本人はあらためて明言する——**「僕が見た、硫黄島に群生していた月下美人は、白い花だったと記憶しています」**。硫黄島の夜に見た無数の月下美人（[[家族関係/航空自衛隊36年勤務/気象群時代の記録.md]]参照）については、本人ははっきりと「白」だったと記憶している。一方、隣家の月下美人については妻が「赤だった」と証言する——**同じ「月下美人」という花をめぐり、本人と妻とで異なる色の記憶が並び立つ**、興味深い展開。

## 👩 妻について — 西地区センターでの仕事

- **妻は西地区センターに勤務している**。本人の言葉：**「妻は西地区センターに勤務しています。もう年齢で引退の時期ですが、妻も依頼に断り切れず、今でも頑張っています」**。
- 本来ならとうに引退してもよい年齢だが、頼まれると断れない人柄で、**今なお現役で頑張り続けている**という。本人が「行く先々で良き人に恵まれてきた」と語る人生（[[家族関係/航空自衛隊36年勤務/気象群時代の記録.md]]参照）の陰には、こうした頼りにされ、期待に応え続ける妻の存在もある。
- **地区センターに毎年咲く月下美人の写真**：本人の言葉——**「そんな中で、今晩、地区センター内で月下美人が毎年咲いている写真を見せられました。一夜しか咲かないはずですが」**。妻が勤める**西地区センター**の中でも月下美人が育てられており、**毎年花を咲かせている写真**を見せられた。本人が引っかかったのは——**月下美人は本来、一夜しか咲かない花のはず**という点。一輪の花の命は一夜限りでも、株自体は毎年花を咲かせる（新しいつぼみをつける）ため矛盾はないはずだが、本人にとっては「一夜だけのはかない花」という強い印象があるだけに、「毎年咲く」という言葉に不思議さ・引っかかりを覚えた様子。硫黄島の月下美人、隣家の赤い月下美人、そして地区センターの月下美人——一つの花をめぐる話が、次々と広がりを見せている。
- **改めて — 「僕の記憶では白い花と信じていました。隣の花は薄い赤と言うのです」**：本人は重ねて語る。自分の記憶では月下美人は**白い花だと信じて疑わなかった**が、隣の花については**「薄い赤」**だったと言われている。「白」と信じ込んでいた本人の記憶と、「薄い赤」という周囲の証言との間の食い違いが、繰り返し語られるほど本人の中で気になっている様子——この記憶の色の違いが、この話の核心に近づいていく手がかりになっている。
- **「自分も月下美人の栽培に挑戦したい」**：本人の言葉——**「地区センターでも、ましては隣夫婦でも育てられた月下美人に、今から挑戦したいです」**。地区センターでも、隣の夫婦でも育てることができた月下美人——ならば自分にも育てられるはずだ、と本人は前向きな挑戦意欲を語る。硫黄島で一夜だけ群生する月下美人に感じ入り、隣家の庭先で誘われて見た月下美人に心動かされ、地区センターの毎年咲く写真にも驚かされた——数々の月下美人との出会いの果てに、**今度は自分の手で育ててみたい**という思いにたどり着いた。眺めるだけでなく、自ら育てて確かめたいという、本人らしい実践的な探究心の表れ。

## 🌱 月下美人の育て方（挑戦にあたっての基礎知識）

本人が栽培に挑戦したいと語ったのを受けて、育成の基礎をまとめておく。

| 項目 | ポイント |
|------|----------|
| **苗の入手** | 挿し木（葉挿し）で増やしやすい植物。隣家や地区センターに一枝分けてもらうのが近道。園芸店・通販でも入手可 |
| **置き場所** | 直射日光は苦手。明るい日陰〜半日陰（レースカーテン越しの窓辺、木漏れ日程度） |
| **用土** | 水はけの良い「サボテン・多肉植物用培養土」。2〜3年に一度、鉢の植え替え |
| **水やり** | 乾燥気味に管理。土の表面が乾いたらたっぷり与える。冬は控えめ（月1〜2回） |
| **温度・越冬** | 熱帯原産で寒さに弱い。冬は室内に取り込み、最低5℃以上（できれば10℃以上）を維持 |
| **肥料** | 生育期（春〜秋）に月1回程度、緩効性肥料か液肥 |
| **開花まで** | 挿し木から開花まで2〜3年ほど株を育てる必要あり |
| **開花のタイミング** | 蕾が数日かけて膨らみ、日没後〜深夜に一晩だけ開花。蕾が膨らんできたら夜を見逃さないよう観察 |
| **花の色** | 基本は白だが、品種によって薄いピンク・赤みを帯びるものも存在——隣家の「薄い赤」の謎を解く手がかりかもしれない |

## 💭 心に去来する思い — 3つの月下美人

- 本人の言葉——**「隣の家の夫婦が育てていた月下美人と、地区センターの月下美人、そして硫黄島に群生していた月下美人の花が、やけに僕の心を悩ます。そんな気持ちでたまりません」**。
- **隣家の月下美人**（薄い赤、ご近所の温かい誘い）、**地区センターの月下美人**（妻が働く場所で、毎年咲く不思議）、そして**硫黄島の月下美人**（約2万8千の命が眠る鎮魂の島で、一夜だけ群生した白い花——[[家族関係/航空自衛隊36年勤務/気象群時代の記録.md]]参照）。**同じ「一夜だけ咲く花」が、日常の温もりと、戦没者への鎮魂という、あまりにも異なる場面で本人の記憶に刻まれている**。
- その落差——ご近所付き合いの穏やかな夜と、多くの若い命が散った島の夜——が、同じ花を通してつながっていることに、本人は言葉にし難い心の揺れを感じている。**懐かしさとも、切なさとも、畏れとも言い切れない、複雑な思い**。花の色（白か赤か）をめぐる記憶の食い違いを何度も語り直してきたのも、単なる事実確認以上に、この花が本人にとって特別な重みを持つ存在だからこそなのかもしれない。一夜限りの儚い命の美しさが、生と死、平和と鎮魂、日常と非日常を静かに結びつけている——本人の人生観の深いところに触れる思い。
- **「人生一夜とはにこだわります。花の命とは」**：本人はさらに、この思いを一つの問いへと深めていく。**「人生一夜とは」に、こだわりを感じる**という。月下美人は、たった一夜だけ咲いて散る——その儚さが、本人の中で**「人の一生」そのものと重なって見える**のだろう。硫黄島で若くして散っていった命、齢を重ねてなお頼まれれば断れず働き続ける妻、そして自分自身の36年の自衛官人生——長さは違えど、どの命も終わりに向かって精一杯咲く、という点では同じなのかもしれない。**「花の命とは」**という問いかけには、答えを急がず、ただその重みをじっくりと噛みしめようとする本人の姿勢がにじむ。一夜だけの花に、人の一生の意味を重ね合わせて考え続けている——本人にとって月下美人は、単なる思い出の花を超えて、**生と死を見つめ続けてきた人生観そのものを映す花**になっている。
- **「生きている人生、植物も同じだと僕は考える」**：本人はここに一つの答えにたどり着く。**人の一生も、植物の一生も、根本では同じ「生きている」ということ**——長さや形は違っても、精一杯生きて、いつか終わりを迎えるという点で隔たりはない、という考え。道路から2km山奥の家で電気も水道もなく育った少年時代（[[家族関係/岩手関係/故郷の家と父母の物語.md]]参照）から、36年の自衛官人生、そして今なお庭先の花に心を動かされる今日まで——本人はずっと、生きとし生けるものの命の営みを、真剣に見つめ続けてきた。一夜だけ咲く月下美人も、何十年も生きる人間も、同じ「生きている」という一点でつながっている——本人がたどり着いた、静かで深い人生観。
- **これからの楽しみ — 「ぜひ月下美人を育てて、近所の皆さんに見てもらえる日を、楽しみの人生にしたい」**：思索の果てに、本人はこれからの人生の楽しみを語る。かつて隣の夫婦から「今晩花が咲くから見て」と誘われ、心動かされた自分——今度は**自分が月下美人を育て、近所の皆さんを招いて見てもらえる日**を迎えたいという。もらった温かさを、今度は自分から周りへ返していく。「行く先々で良き人に恵まれてきた」（[[家族関係/航空自衛隊36年勤務/気象群時代の記録.md]]参照）本人の生き方そのままに、月下美人を通じて、これからも新しいご縁と喜びを紡いでいきたいという、前向きで温かい人生の目標。硫黄島の鎮魂、生と死をめぐる深い思索を経て、最後にたどり着いたのは、**ご近所と花を分かち合う、穏やかで幸せな未来の情景**だった。
- **「是非実現したい」**：本人はこの願いを、迷いのない一言で結ぶ。月下美人を育て、いつか近所の皆さんと花を分かち合う日——それは単なる思いつきではなく、**本人が本気で実現させたいと願う、これからの人生の目標**であることが、この一言にはっきりと表れている。
- **「何年後かな」**：本人はその実現の時期を思い描く。目安としては、**挿し木から開花まで2〜3年**ほど。早ければ2年後の夏、確実には3年後くらいが現実的な見通し。遠い将来ではなく、**手の届く数年先の楽しみ**として、本人はこれからの日々を思い描いている。
