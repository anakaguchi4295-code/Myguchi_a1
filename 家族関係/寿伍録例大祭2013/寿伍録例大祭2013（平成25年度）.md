平沼2丁目の町内会「平沼寿伍録」は、水天宮平沼神社の氏子町内の一つ。この年の例大祭で、実行委員長・氏子世話人会・子供神輿担当の3つの役職を務めた際の記録・資料写真一式。

### 各役職の役割
| 役職 | 役割 |
|------|------|
| **実行委員長** | 祭礼運営の**全て**を統括する立場 |
| **氏子世話人会** | 氏子各町内が合同で行う**連合渡御（連合統御）を司る**役割 |
| **子供神輿担当** | 子供神輿・山車の運営を担当 |

## ⚖️ 祭礼委員長（実行委員長）の責任とは

一般的な神社祭礼における実行委員長の責任を整理すると、以下のような多層的な役割がある。

| 責任の種類 | 内容 |
|------|------|
| **① 運営全体の統括** | 神輿・山車・受付・接待など各係がうまく噛み合うよう調整し、問題発生時の最終判断を下す総責任 |
| **② 氏子・関係団体との調整** | 氏子世話人会・子供会・婦人部・青壮年部など複数世代の団体、さらに神社（宮司）・警察（交通規制）・近隣住民との折衝 |
| **③ 安全管理** | 神輿渡御・子供神輿・山車運行における事故・熱中症などのリスク管理（順路図の休憩所配置もこの一環） |
| **④ 予算・経費管理** | 奉納金・寄付金の集金、御酒所の設営費、警備費などの会計管理 |
| **⑤ 長時間の現場対応** | 夕方から深夜まで数時間にわたる拘束、複数地域・団体との同時進行の調整 |
| **⑥ 次世代への引き継ぎ** | 役割分担表・順路図・記録を翌年以降の担当者に残すこと |

### 💭 ご自身の経験に当てはめて

平成25年度は「実行委員長」として①②の総括・調整責任を担いつつ、「氏子世話人会」として連合渡御の采配（②の一部）、「子供神輿担当」として⑤の現場実務まで、**3階層すべてに責任を持つ**、かなり負荷の大きい体制だった。役割分担表を見ても他の役職は1〜2名の分担に対し、複数役を兼任されていたのは、相当な信頼と実務能力を買われてのことだったと考えられる。
