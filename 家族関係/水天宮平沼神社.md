# 水天宮平沼神社 — 歴史・世話人会・9月の例大祭

横浜市西区にある地元の氏神様。妻の故郷・石川ゆかりの神社は[[家族関係/石川関係/お熊甲神社（久麻加夫都阿良加志比古神社）.md]]、同じ平沼エリアの地名・町内会名の言い伝えは[[家族関係/平沼の地名と町内会名の言い伝え.md]]参照。本人が実行委員長・氏子世話人会・子供神輿担当を務めた平成25年度（2013年）の記録は[[家族関係/寿伍録例大祭2013/寿伍録例大祭2013（平成25年度）|寿伍録例大祭2013（平成25年度）]]、祭礼でお世話になった大先輩・高橋さんの切り絵作品集は[[家族関係/高橋さんの切り絵作品集/高橋さんの切り絵作品集|高橋さんの切り絵作品集]]を参照。

## ⛩️ 歴史・由緒

| 時期                    | 出来事                                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **天保10年（1839年）**      | 平沼九兵衛翁が「平沼新田」を開拓した際、新田の守護神として創建。185年以上の歴史を持つ                                                                       |
| 創建の逸話                 | 塩田作業中の村人が、入江に流れ着いた祠を何度も岸に戻したことから、九兵衛翁が「新田に守護神がないため、神様がこの地にお着きになった」と感謝して祀った。祠の中には九州・久留米の水天宮の御神札が納められていたため「水天宮」と称された |
| **文久2年（1862年）**       | 帷子川沿い（現・西区西平沼町、元平沼橋付近）から現在地へ遷座                                                                                     |
| **明治4年（1871年）**       | 社格制度の制定により、平沼の鎮守として村社に列格。名称も「水天宮」から「平沼神社」に改称                                                                       |
| **大正2年（1913年）**       | 本殿前に拝殿を新築し、現在の社殿が完成                                                                                                |
| **大正12年（1923年）関東大震災** | 社殿は倒壊を免れた                                                                                                          |
| **昭和20年（1945年）横浜大空襲** | 横浜市内が焼け野原になる中、鎮座地一帯だけは焼け残った                                                                                        |

### ご祭神とご利益
- **安徳天皇**（水天宮の神）を中心に、天御中主大神などを「水天宮の大神」として祀る。
- 上記の震災・空襲を免れた逸話から、**安産・水徳**に加え**「火難除け」**の神社としても篤く信仰されている。
- 現在は横浜駅東口に近い**高島町・平沼町・西平沼町**一帯の鎮守（産土神）。

## 🤝 世話人会について

「世話人会」は、この神社に限らず日本の氏神神社に一般的な組織で、実質的に**「氏子総代」「氏子世話人」**とほぼ同じ意味で使われる。

- **役割**：氏子（氏神を信仰する地域住民）の代表として、宮司と協力しながら祭礼・行事の企画運営、神社の維持管理・清掃、氏子への連絡や祭礼費用の集金などを担う、いわば「神社と地域をつなぐ世話役」。
- 例大祭では、氏子町内（平沼神社の場合は高島町・平沼町・西平沼町など）ごとに神輿を出す町内神輿・連合渡御の采配、神酒所（御神酒所）の設営、奉納行事の手配などを世話人会が中心になって取り仕切るのが一般的な形。

※平沼神社独自の世話人会の具体的な構成メンバーや詳細な内規まではWeb上に公開情報が見当たらなかった。より詳しく知りたい場合は、神社の社務所に直接問い合わせるか、氏子町内会の掲示・回覧などで確認するのが確実。
